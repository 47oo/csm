# 资源领域分析

先读取 `AGENTS.md` 与本次涉及的 V2 产品文档。领域事实保存在 `docs/product/domain-model.md`；尚未建立时按 AGENTS §1.1 从已确认需求开展澄清，不回查旧版本。决策状态与权威顺序不在本 Skill 重复定义。

## 分析步骤

1. 判定需求涉及登记、关系、生命周期、状态维护、实时状态、容量、可用性或查询展示。
2. 对数据逐项确认：来源、维护者、变化频率、历史需求、唯一性/完整性边界和关联对象。
3. 判断需要新对象、关系、字段、状态，还是仅查询视图；出现名词不等于需要新实体或表。
4. 将新增或冲突规则交 Product Manager / 用户确认，记录受影响的产品文档；核对已裁定问题，不重复提出已关闭事项。

输出领域影响、确认依据与真正未决问题，作为当前角色公共交接报告的一部分，不另建重复的领域模型或独立报告。
