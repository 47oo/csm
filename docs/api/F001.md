## 0. 通用约定

- 认证：HttpOnly Cookie `csm_session`（复用 F013，HTTP-only、无 `Secure`）。未认证 → `401 UNAUTHENTICATED`。
- 权限（服务端）：
  - 列表/详情：任意已登录（`viewer`/`maintainer`/`admin`）；
  - 新增/编辑：仅 `admin`；越权 → `403 FORBIDDEN`，数据不变；
  - 真实删除：`maintainer`/`admin`；越权 → `403 FORBIDDEN`。
- 首登改密拦截由 F013 统一处理（`403 PASSWORD_CHANGE_REQUIRED`）。
- `code` 规范化：`normalize_cluster_code(raw) = upper(trim(raw))`；规范化后须匹配 `^[A-Z0-9]{1,32}$`。判重与二次确认比较均使用该值（`code_key`）。展示值（`code` 字段）为去首尾空格后的用户输入，保留大小写（ADR-002）。
- 名称：仅字母/中文/下划线/数字，长度 1–64；含空格（首/尾/中）直接拒绝、不裁剪；仍存集群内**区分大小写**唯一；真实删除后可复用。
- 分页：`page`（int，默认 1，≥1）、`page_size`（int，默认 20，1–100）；返回 `total`。排序 `sort`，允许 `code`/`-code`/`name`/`-name`/`created_at`/`-created_at`，默认 `code`。

### Problem+json（所有 4xx/5xx）
```json
{
  "type": "about:blank",
  "title": "string",
  "status": 422,
  "code": "VALIDATION_ERROR",
  "message": "string",
  "errors": [
    { "field": "code", "code": "CODE_FORMAT", "message": "集群 code 规范化后仅允许大写字母与数字，长度 1–32" }
  ]
}
```
`errors` 可空/缺省。

### 错误码总表
| code | HTTP | 语义 |
| --- | --- | --- |
| `INVALID_REQUEST` | 400 | 请求体/参数格式非法（含编辑不可改字段、无可改字段、非法排序/过滤） |
| `VALIDATION_ERROR` | 422 | 字段级校验失败（`errors[]`） |
| `DELETE_CONFIRMATION_MISMATCH` | 422 | 二次确认输入与集群名称或 `code` 不匹配 |
| `UNAUTHENTICATED` | 401 | 无有效会话 |
| `FORBIDDEN` | 403 | 角色不足 |
| `CLUSTER_NOT_FOUND` | 404 | 集群不存在 |
| `CLUSTER_CODE_TAKEN` | 409 | `code` 规范化后与仍存或已真实删除集群的 `code` 冲突（不复用） |
| `CLUSTER_NAME_TAKEN` | 409 | 名称与仍存集群重复（区分大小写） |
| `CLUSTER_HAS_ASSOCIATIONS` | 409 | 仍存在计算资源/网段/服务等业务关联，禁止真实删除 |
| `VERSION_CONFLICT` | 409 | 乐观锁冲突 |

## 2. 集群端点

### 2.1 GET `/clusters`
- 权限：任意已登录。
- Query：
  | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | page | integer | 否 | 默认 1 |
  | page_size | integer | 否 | 默认 20，1–100 |
  | q | string | 否 | 去首尾空格；匹配集群编号或名称（英文不区分大小写、包含匹配，`%`/`_` 按普通字符） |
  | sort | string | 否 | 默认 `code` |
- Response `200`：`PagedClusters`。
- 边界：无匹配 → `200` + `items: []`、`total: 0`。
- 错误：`401 UNAUTHENTICATED`；`400 INVALID_REQUEST`（非法 `sort`/`page_size`）。

### 2.2 POST `/clusters`
- 权限：仅 `admin`。
- Request：
```json
{ "code": "string", "name": "string", "purpose": "string" }
```
  | 字段 | 类型 | 必填 | 校验 |
  | --- | --- | --- | --- |
  | code | string | 是 | 去首尾空格+统一大写后匹配 `^[A-Z0-9]{1,32}$` |
  | name | string | 是 | `^[A-Za-z0-9_\u4e00-\u9fff]{1,64}$`（具体字符集见架构 §8 PROPOSED-1） |
  | purpose | string | 是 | 非空；长度上限见架构 §8 PROPOSED-2 |
- Response `201`：`ClusterDetail`。
- 错误：`422 VALIDATION_ERROR`（`errors[].code` ∈ `CODE_FORMAT`/`NAME_FORMAT`/`PURPOSE_INVALID`）；`409 CLUSTER_CODE_TAKEN`；`409 CLUSTER_NAME_TAKEN`；`403 FORBIDDEN`。
- 语义：同事务先写 `reserved_cluster_codes`（冲突→`CLUSTER_CODE_TAKEN`）后创建；写 `cluster.create` 审计。

### 2.3 GET `/clusters/{cluster_id}`
- Path：`cluster_id` integer。
- 权限：任意已登录。
- Response `200`：`ClusterDetail`。
- 错误：`404 CLUSTER_NOT_FOUND`；`401 UNAUTHENTICATED`。

### 2.4 PATCH `/clusters/{cluster_id}`
- 权限：仅 `admin`。
- Request（`version` 必填；**`code` 不可修改**）：
```json
{ "name": "string", "purpose": "string", "version": 3 }
```
  | 字段 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | name | string | 否 | 同 POST 名称校验；省略=不修改 |
  | purpose | string | 否 | 非空；省略=不修改 |
  | version | integer | 是 | 乐观锁 |
- Response `200`：`ClusterDetail`（`version` 已自增）。
- 错误：`400 INVALID_REQUEST`（含 `code` 字段或无可改字段，`errors[].code=CODE_IMMUTABLE`/`NO_FIELDS`）；`403 FORBIDDEN`；`404 CLUSTER_NOT_FOUND`；`409 CLUSTER_NAME_TAKEN`；`409 VERSION_CONFLICT`；`422 VALIDATION_ERROR`。
- 语义：仅名称/用途可变；`code` 创建后不可改；改名不改 `code`、不改既有资源/网段/服务归属；写 `cluster.update` 审计与 `resource_history`。

### 2.5 DELETE `/clusters/{cluster_id}`
- 权限：`maintainer`/`admin`。
- Query：
  | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | confirm | string | 是 | 二次确认：去首尾空格后须等于集群名称（区分大小写）**或** `upper(trim(confirm))` 等于 `code_key` |
  | version | integer | 是 | 乐观锁 |
- Response `204`。
- 错误：`404 CLUSTER_NOT_FOUND`；`422 DELETE_CONFIRMATION_MISMATCH`（不执行删除）；`409 CLUSTER_HAS_ASSOCIATIONS`；`409 VERSION_CONFLICT`；`403 FORBIDDEN`。
- 语义：真实删除，无恢复入口；删除前同一事务写入 `cluster.delete` 审计与 `resource_history`；删除后 `code` 永不复用、名称可复用、审计与历史保留。
- 校验顺序（建议）：`401/403` → `404` → `422`（确认不匹配）→ `409 CLUSTER_HAS_ASSOCIATIONS` → `409 VERSION_CONFLICT`。

## 3. 业务边界汇总

| 边界 | 结果 |
| --- | --- |
| 空集群列表 | `200`，`items: []`，`total: 0` |
| 不存在的集群（详情/编辑/删除） | `404 CLUSTER_NOT_FOUND` |
| `code` 规范化后非法或长度越界 | `422 VALIDATION_ERROR`（`field=code`, `code=CODE_FORMAT`） |
| `code` 与仍存或已真实删除集群等价 | `409 CLUSTER_CODE_TAKEN`（永不复用） |
| 编辑请求包含 `code` | `400 INVALID_REQUEST`（`errors[].code=CODE_IMMUTABLE`） |
| 名称含空格或非法字符 | `422 VALIDATION_ERROR`（`field=name`, `code=NAME_FORMAT`） |
| 名称与仍存集群完全相同 | `409 CLUSTER_NAME_TAKEN`（区分大小写） |
| 名称大小写不同但字符相同（如 `ABC` vs `abc`） | 允许 |
| 名称与已真实删除集群相同 | 允许（名称可复用） |
| 仍有关联时真实删除 | `409 CLUSTER_HAS_ASSOCIATIONS`，不级联 |
| 仅余历史已解除关联 | 允许删除（历史不阻塞） |
| `confirm` 不匹配名称或 `code` | `422 DELETE_CONFIRMATION_MISMATCH`，不删除 |
| 查看者调用新增/编辑/删除 | `403 FORBIDDEN`，数据不变 |
| 维护者调用新增/编辑 | `403 FORBIDDEN` |
| 并发编辑/删除 | `409 VERSION_CONFLICT`，前端保留输入 |
| 未登录访问受保护端点 | `401 UNAUTHENTICATED` |
