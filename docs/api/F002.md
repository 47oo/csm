## 0. 通用约定

- 认证：HttpOnly Cookie `csm_session`（复用 F013，HTTP-only、无 `Secure`）。未认证 → `401 UNAUTHENTICATED`。
- 权限（服务端）：
  - 详情（供表单加载）：任意已登录（`viewer`/`maintainer`/`admin`）；
  - 新增/编辑：`maintainer`/`admin`；越权 → `403 FORBIDDEN`，数据不变；
  - 真实删除：`maintainer`/`admin`；越权 → `403 FORBIDDEN`。
- 首登改密拦截由 F013 统一处理（`403 PASSWORD_CHANGE_REQUIRED`）。
- 名称口径（BQ-W）：资源名、接口名**去首尾空格后存储/比较、区分大小写、禁止纯空白**。资源名同集群仍存资源（裸金属 + VM）统一唯一；接口名同一资源内唯一。
- 资源类型 `resource_type`：`bare_metal` | `virtual_machine`；创建后只读。
- 状态 `status`：`IDLE` | `ALLOC` | `DOWN` | `UNKNOWN`；未提供默认 `ALLOC`；状态来源仅记录操作者，仅保留状态更新时间（BQ-AA）。
- 网卡 `segment_id`：`null` 或本资源**同集群仍存**网段 ID（0..1）；本阶段网卡不携带 IP、不携带 technology/purpose/VLAN/网关（由所选网段只读带出）。
- 整单原子（§4.5）：一次请求提交公共信息 + 全部网卡，单事务；任一失败整单不生效。
- 显式网卡操作（ADR-003）：编辑时 `interfaces[]` 每项须声明 `op`；未列入 `interfaces[]` 的既有网卡视为**未修改**。
- 记录级错误定位：`errors[].field` 支持数组下标定位（如 `interfaces[1].name`）。

### Problem+json（所有 4xx/5xx）
```json
{
  "type": "about:blank",
  "title": "string",
  "status": 409,
  "code": "RESOURCE_NAME_EXISTS",
  "message": "string",
  "existing_resource_id": 123,
  "existing_resource_type": "bare_metal",
  "errors": [
    { "field": "interfaces[1].segment_id", "code": "INTERFACE_SEGMENT_CLUSTER_MISMATCH", "message": "网段必须与本资源同集群" }
  ]
}
```
- `errors` 可空/缺省。
- 扩展成员 `existing_resource_id`（integer，可缺省）、`existing_resource_type`（string，可缺省）仅用于 `RESOURCE_NAME_EXISTS`，供前端提示进入既有资源编辑。

### 错误码总表
| code | HTTP | 语义 |
| --- | --- | --- |
| `INVALID_REQUEST` | 400 | 请求体/参数格式非法（含编辑不可改字段、无可改字段、非法网卡 `op`）；`errors[].code` ∈ `RESOURCE_TYPE_IMMUTABLE`/`RESOURCE_CLUSTER_IMMUTABLE`/`NO_FIELDS`/`INVALID_INTERFACE_OP` |
| `VALIDATION_ERROR` | 422 | 字段级校验失败（`errors[]`）；`errors[].code` ∈ `NAME_FORMAT`/`RESOURCE_TYPE_INVALID`/`STATUS_INVALID`/`INTERFACE_NAME_FORMAT`/`INTERFACE_NAME_DUPLICATE_IN_PAYLOAD`/`INTERFACE_NOT_FOUND`/`INTERFACE_SEGMENT_INVALID`/`INTERFACE_SEGMENT_CLUSTER_MISMATCH` |
| `DELETE_CONFIRMATION_MISMATCH` | 422 | 二次确认输入与资源名称不匹配 |
| `UNAUTHENTICATED` | 401 | 无有效会话 |
| `FORBIDDEN` | 403 | 角色不足 |
| `RESOURCE_NOT_FOUND` | 404 | 资源不存在 |
| `CLUSTER_NOT_FOUND` | 404 | 新增时 `cluster_id` 不存在 |
| `RESOURCE_NAME_EXISTS` | 409 | 同集群已存在同名仍存资源（不创建第二条）；响应附 `existing_resource_id` |
| `INTERFACE_NAME_TAKEN` | 409 | 同一资源下接口名重复 |
| `RESOURCE_HAS_INTERFACES` | 409 | 仍有网卡未逐项删除，禁止真实删除 |
| `VERSION_CONFLICT` | 409 | 乐观锁冲突 |

> F006 引入 IP 后可能新增 IP 相关错误码；本 Contract 仅覆盖无 IP 阶段。

## 1. Schema

### InterfaceSegmentSummary（便利字段，只读）
| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| id | integer | 否 | 网段 ID |
| name | string | 否 | 网段名称 |
| cidr | string | 否 | 规范化 IPv4 CIDR |
| purpose | string | 否 | 用途 |
| technology | string | 否 | 技术类型 |
| vlan | integer | 是 | VLAN；未填 `null` |
| gateway | string | 是 | 网关；未设 `null` |

> 用于表单内「选定网段后只读带出技术/用途/前缀/网关」（§4.2.7、场景 28）；数据来源为 F005。

### NetworkInterfaceResource（响应中的网卡）
| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| id | integer | 否 | 网卡 ID |
| name | string | 否 | 接口名（去首尾空格） |
| segment_id | integer | 是 | 关联网段；未选 `null` |
| segment | InterfaceSegmentSummary | 是 | 关联网段摘要；未选 `null`（便利字段） |
| created_at | string(date-time) | 否 | |
| updated_at | string(date-time) | 否 | |

### ResourceFormDetail（`GET`/`POST`/`PATCH` 响应）
| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| id | integer | 否 | 资源 ID（稳定标识） |
| cluster_id | integer | 否 | 所属集群 ID |
| cluster_code | string | 否 | 所属集群展示编号（便利字段） |
| cluster_name | string | 否 | 所属集群名称（便利字段） |
| name | string | 否 | 资源名称 |
| resource_type | string | 否 | `bare_metal`/`virtual_machine` |
| status | string | 否 | `IDLE`/`ALLOC`/`DOWN`/`UNKNOWN` |
| status_updated_by | integer | 是 | 状态来源操作者用户 ID；无记录 `null` |
| status_updated_by_username | string | 是 | 状态来源操作者用户名（便利字段）；不可解析 `null` |
| status_updated_at | string(date-time) | 否 | 状态更新时间 |
| interfaces | NetworkInterfaceResource[] | 否（空为 `[]`） | 网卡列表（按 `name` 稳定排序） |
| version | integer | 否 | 乐观锁 |
| created_at | string(date-time) | 否 | |
| updated_at | string(date-time) | 否 | |

### NetworkInterfaceCreate（请求）
| 字段 | 类型 | 必填 | 校验 |
| --- | --- | --- | --- |
| name | string | 是 | 去首尾空格非空、区分大小写、同资源内唯一 |
| segment_id | integer\|null | 否 | 省略或 `null` = 不选网段；非空须为同集群仍存网段 |

### NetworkInterfaceOp（编辑请求中的网卡项，判别字段 `op`）
| 字段 | 类型 | 适用 op | 校验 |
| --- | --- | --- | --- |
| op | string | 全部 | `create`/`update`/`delete`；其它值 → `400 INVALID_INTERFACE_OP` |
| id | integer | `update`/`delete` | 须属于该资源，否则 `422 INTERFACE_NOT_FOUND` |
| name | string | `create`/`update` | `create` 必填；`update` 省略=不修改；同资源内唯一 |
| segment_id | integer\|null | `create`/`update` | 省略=不修改（`update`）/不选网段（`create`）；`null`=清空；非空须为同集群仍存网段 |

> 未出现在 `interfaces[]` 中的既有网卡视为**未修改**。

## 2. 资源端点

### 2.1 POST `/resources`
- 权限：`maintainer`/`admin`。
- Request：
```json
{
  "cluster_id": 1,
  "name": "cn001",
  "resource_type": "bare_metal",
  "status": "ALLOC",
  "interfaces": [
    { "name": "eth0", "segment_id": 3 },
    { "name": "ib0", "segment_id": null }
  ]
}
```
  | 字段 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | cluster_id | integer | 是 | 集群须存在，否则 `404 CLUSTER_NOT_FOUND` |
  | name | string | 是 | 去首尾空格非空、区分大小写、同集群仍存资源统一唯一 |
  | resource_type | string | 是 | `bare_metal`/`virtual_machine` |
  | status | string | 否 | 默认 `ALLOC` |
  | interfaces | NetworkInterfaceCreate[] | 否 | 缺省=空数组；同 payload 内接口名不得重复 |
- Response `201`：`ResourceFormDetail`。
- 错误：`403 FORBIDDEN`；`404 CLUSTER_NOT_FOUND`；`409 RESOURCE_NAME_EXISTS`（附 `existing_resource_id`，不创建第二条）；`422 VALIDATION_ERROR`（`NAME_FORMAT`/`RESOURCE_TYPE_INVALID`/`STATUS_INVALID`/`INTERFACE_NAME_FORMAT`/`INTERFACE_NAME_DUPLICATE_IN_PAYLOAD`/`INTERFACE_SEGMENT_INVALID`/`INTERFACE_SEGMENT_CLUSTER_MISMATCH`）；`409 INTERFACE_NAME_TAKEN`（与既有网卡冲突）。
- 语义：单事务创建资源与全部网卡；`status_updated_by`=操作者、`status_updated_at`=now；写 `resource.create` 审计与（如适用）资源历史便于追溯（`PROPOSED`：create 仅写审计）。

### 2.2 GET `/resources/{resource_id}`
- Path：`resource_id` integer。
- 权限：任意已登录。
- Response `200`：`ResourceFormDetail`（供新增/编辑表单加载，含网卡与 `version`）。
- 错误：`404 RESOURCE_NOT_FOUND`；`401 UNAUTHENTICATED`。
- 边界：资源不存在 → `404`；无网卡 → `interfaces: []`。
- 说明：统一资源列表、筛选、分页、搜索与公共详情展示页由 F003 交付（本端点为表单加载用途）。

### 2.3 PATCH `/resources/{resource_id}`
- 权限：`maintainer`/`admin`。
- Request（`version` 必填；省略字段=不修改；`resource_type`/`cluster_id` 只读）：
```json
{
  "name": "cn001-new",
  "status": "DOWN",
  "interfaces": [
    { "op": "create", "name": "ib1", "segment_id": 4 },
    { "op": "update", "id": 10, "segment_id": 5 },
    { "op": "delete", "id": 11 }
  ],
  "version": 3
}
```
  | 字段 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | name | string | 否 | 省略=不修改；同集群唯一 |
  | status | string | 否 | 省略=不修改；变更时刷新 `status_updated_by`/`status_updated_at` |
  | interfaces | NetworkInterfaceOp[] | 否 | 省略或 `[]`=不改动网卡；显式 `op` 增/改/删 |
  | version | integer | 是 | 乐观锁 |
  | resource_type | string | — | 只读：与当前不同 → `400 RESOURCE_TYPE_IMMUTABLE`；相同→忽略 |
  | cluster_id | integer | — | 只读：与当前不同 → `400 RESOURCE_CLUSTER_IMMUTABLE`；相同→忽略 |
- Response `200`：`ResourceFormDetail`（`version` 已自增）。
- 错误：`400 INVALID_REQUEST`（`RESOURCE_TYPE_IMMUTABLE`/`RESOURCE_CLUSTER_IMMUTABLE`/`NO_FIELDS`/`INVALID_INTERFACE_OP`）；`403 FORBIDDEN`；`404 RESOURCE_NOT_FOUND`；`409 RESOURCE_NAME_EXISTS`/`INTERFACE_NAME_TAKEN`/`VERSION_CONFLICT`；`422 VALIDATION_ERROR`（含 `INTERFACE_NOT_FOUND`/`INTERFACE_SEGMENT_INVALID`/`INTERFACE_SEGMENT_CLUSTER_MISMATCH`/`INTERFACE_NAME_DUPLICATE_IN_PAYLOAD`）。
- 语义：单事务锁定资源行、校验、应用资源字段变更与网卡显式增/改/删、写 `resource.update` 审计与 `resource_history(update)`；任一失败整单回滚。

### 2.4 DELETE `/resources/{resource_id}`
- 权限：`maintainer`/`admin`。
- Query：
  | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | confirm | string | 是 | 二次确认：去首尾空格后须等于资源名称（区分大小写） |
  | version | integer | 是 | 乐观锁 |
- Response `204`。
- 错误：`404 RESOURCE_NOT_FOUND`；`422 DELETE_CONFIRMATION_MISMATCH`（不执行删除）；`409 RESOURCE_HAS_INTERFACES`；`409 VERSION_CONFLICT`；`403 FORBIDDEN`。
- 语义：真实删除、无恢复入口、不级联；删除前须已逐项删除其仍存网卡（通过编辑显式 `op:"delete"`）；删除前同事务写 `resource.delete` 审计与 `resource_history(delete)`；历史保留。
- 校验顺序（建议）：`401/403` → `404` → `422`（确认不匹配）→ `409 RESOURCE_HAS_INTERFACES` → `DELETE ... WHERE id AND version` → `23503` 映射 → rowcount 0 → `404`/`409 VERSION_CONFLICT`。

## 3. 业务边界汇总

| 边界 | 结果 |
| --- | --- |
| 不存在的资源（详情/编辑/删除） | `404 RESOURCE_NOT_FOUND` |
| 新增时 `cluster_id` 不存在 | `404 CLUSTER_NOT_FOUND` |
| 资源无网卡 | `interfaces: []`（合法） |
| 同集群同名仍存资源（新增或改名） | `409 RESOURCE_NAME_EXISTS`，附 `existing_resource_id`；不创建第二条、不覆盖、不合并 |
| 同集群名称大小写不同（如 `cn001` vs `CN001`） | 允许（区分大小写） |
| 跨集群同名 | 允许 |
| 裸金属与 VM 同名（同集群） | 拒绝（统一判重） |
| 同一资源下接口名重复（与既有） | `409 INTERFACE_NAME_TAKEN` |
| 同一 payload 内接口名重复 | `422 VALIDATION_ERROR`（`INTERFACE_NAME_DUPLICATE_IN_PAYLOAD`） |
| 接口名含首尾空格 | 去首尾空格后存储；纯空白拒绝 |
| `interfaces` 省略或 `[]` | 网卡未修改（不删除） |
| 显式 `op:"delete"` | 删除该网卡；无恢复入口 |
| 引用不存在网段 | `422 VALIDATION_ERROR`（`INTERFACE_SEGMENT_INVALID`） |
| 引用跨集群网段 | `422 VALIDATION_ERROR`（`INTERFACE_SEGMENT_CLUSTER_MISMATCH`） |
| 网卡引用非本资源的网卡 ID（update/delete） | `422 VALIDATION_ERROR`（`INTERFACE_NOT_FOUND`） |
| 编辑传不同 `resource_type` | `400 INVALID_REQUEST`（`RESOURCE_TYPE_IMMUTABLE`） |
| 编辑传不同 `cluster_id` | `400 INVALID_REQUEST`（`RESOURCE_CLUSTER_IMMUTABLE`） |
| 编辑无任何可改字段 | `400 INVALID_REQUEST`（`NO_FIELDS`） |
| 删除时仍有网卡 | `409 RESOURCE_HAS_INTERFACES`，不级联 |
| 删除 `confirm` 不匹配资源名称 | `422 DELETE_CONFIRMATION_MISMATCH`，不删除 |
| 改名后网卡归属 | 不变（以 `resource_id` 关联） |
| 查看者调用新增/编辑/删除 | `403 FORBIDDEN`，数据不变 |
| 并发编辑/删除（旧 version） | `409 VERSION_CONFLICT`，前端保留输入 |
| 未登录访问受保护端点 | `401 UNAUTHENTICATED` |
