## 1. 通用约定

- Base path /api/v1（§25），挂载同一 api_v1_router。
- 认证：csm_session HttpOnly Cookie（复用 F002 DR-08）；未认证先于权限返回 401。
- 时间：ISO-8601 UTC，例 2026-10-06T12:00:00+00:00（D01；DB timestamptz）。
- 操作者：服务端从 request.state.operator 取，写 Audit 的 operator_user_id(users.id)+operator_username 快照（复用 F002；§22）。请求体不接受操作者字段。
- CSRF：不安全方法沿用 F002 §2.1；GET/HEAD 不校验。

### 1.1 统一错误信封（复用 F002 §1.1）

```json
{ "error": { "code": "STRING_CODE", "message": "human readable", "details": {} } }
```

### 1.2 错误码与 HTTP 映射（F002 错误码集 + F003 扩展 CONFLICT）

| HTTP | code | 触发 | details |
| --- | --- | --- | --- |
| 401 | AUTH_REQUIRED | 无有效会话（复用 F002） | {} |
| 403 | FORBIDDEN | 已认证缺权限 | {"reason":"permission"} |
| 403 | FORBIDDEN | CSRF 校验失败（复用 F002） | {"reason":"csrf"} |
| 404 | NOT_FOUND | 不存在；或已软删且调用者无 VIEW_DELETED（不泄露存在性）；或未定义路径 | {} |
| 409 | VERSION_CONFLICT | 乐观锁过期（复用 F002） | {"current_version": int} |
| 409 | CONFLICT | F003 新增：唯一性/引用/恢复冲突 | 见下表 |
| 422 | VALIDATION_ERROR | 请求体/查询参数校验失败 | {"fields":[{"field":str,"message":str}]} |
| 500 | INTERNAL_ERROR | 未预期错误（不含堆栈/凭据） | {} |

CONFLICT 的 details.reason 枚举：

| reason | 场景 | 附加字段 |
| --- | --- | --- |
| unique_conflict | code 归一化后与现存（含软删）冲突（创建）；恢复重检唯一冲突 | field（如 "code"） |
| reference_exists | 删除对象仍被其它未删除对象引用 | references:[{object_type,object_id,label}]（F003 cluster 集为空，始终存在但通常空数组） |
| not_deleted | 对未软删对象执行 restore | {} |
| dependency_deleted | 恢复重检发现依赖对象仍软删 | conflicts:[{object_type,object_id}] |

错误码注册表以 docs/api/F002.md §1.2 为共享权威；F003 新增 CONFLICT 一行（协调器同步交叉引用）。

### 1.3 权限（§23，复用 F002 §3）

列表/详情/模糊=READ；创建/更新=WRITE；删除（软删）=DELETE_OBJECT；查看已删除（deleted=include|only、详情 deleted=true）=VIEW_DELETED；恢复=RESTORE；Activity=VIEW_ACTIVITY（全角色）。服务端执行；前端隐藏不替代；INACTIVE 对象仍按此权限维护（§5/T29）。

## 2. 字段契约与归一化

### 2.1 Cluster code（D01 裁定，取代 architecture DR-24）

服务端先 trim（去首尾 Unicode 空白）→ 校验 → 存展示列 code（trim 后保留大小写）。trim 后非空；禁止内部空白（Unicode White_Space）与控制字符（Cc/Cf）；**允许中文及其它 Unicode 字符**；长度（Unicode code point）1–64。归一化键 code_key 仅将 ASCII `a-z` 折叠为 `A-Z`（对 btrim(code) 后逐字符；非 ASCII 含中文原样保留，不使用 upper()/str.upper()）；内部列不暴露；ASCII 范围的大小写不敏感唯一由 code_key 承载。DB 对应用 `translate(btrim(code), 'abcdefghijklmnopqrstuvwxyz','ABCDEFGHIJKLMNOPQRSTUVWXYZ')` 保持同口径（F003-REV-1）。**全量唯一（含软删）**，软删后不重用。**创建后不可改**：PATCH 含 code（任意值）→422。依据：§5 未限定 code 字符集且示例含中文候选（山河3/亘聪集群），§4.1 通用规则；属 §35.3 D01。DB ck_clusters_code_*/uq_clusters_code_key 一致。示例：" N96P "→存 N96P，与 n96p 触 unique_conflict。

### 2.2 Cluster name（§5/§4.1）

trim 首尾空白；trim 后非空；禁控制字符（Cc/Cf）；长度 1–255（Unicode code point）；允许中文；保留大小写；允许内部普通空格；无唯一；可修改；不作关联标识。

### 2.3 长度口径（镜像 DB）

code 64 / name 255 / activity.operator_username 64（Unicode code point）。

## 3. Cluster 响应对象

| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| id | string(UUID) | 否 | 稳定 ID（§4） |
| code | string | 否 | trim 后；§2.1 |
| name | string | 否 | trim 后；允许中文 |
| status | enum | 否 | ACTIVE\|INACTIVE；默认 ACTIVE |
| description | string | 是 | 未设置 null |
| metadata | object | 否 | 默认 {}；整值替换 |
| version | int ≥1 | 否 | 乐观锁；创建默认 1 |
| created_at | ISO-8601 UTC | 否 | |
| updated_at | ISO-8601 UTC | 否 | 业务写维护 |
| deleted_at | ISO-8601 UTC | 是 | 未删 null |

code_key 不暴露。

## 4. 分页/排序/过滤/模糊（列表契约基线）

响应 {items, page, page_size, total}；page ≥1 默认1；page_size 1–100 默认20（越界/非整数 422）。sort ∈ {code,name,status,created_at,updated_at} 默认 created_at；order ∈ {asc,desc} 默认 desc（非法 422）；排序附 id 升序稳定；sort=code 按 code_key。过滤：status（枚举，非法 422，省略不过滤）；code（精确，归一化后比 code_key，格式非法 422）；q（code/name 大小写不敏感子串 ILIKE，F003 不引入 pg_trgm，DB-D30）；条件 AND 组合（§25）。排序/过滤仅作用于可见集合。

## 5. 软删可见性

默认 deleted=exclude（仅 deleted_at IS NULL）；include=未删+已删；only=仅已删；include/only 需 VIEW_DELETED 否则 403 FORBIDDEN{reason:permission}；非法值 422。已删详情需显式 ?deleted=true 且具 VIEW_DELETED；显式 deleted=true 但无 VIEW_DELETED → 403 FORBIDDEN{reason:permission}（与 §6.3 一致）；默认视图下软删对象不可见，返回 404（不泄露存在性）。Activity 对已删同理。

## 6. Endpoints

### 6.1 GET /api/v1/clusters — READ（deleted=include|only 另需 VIEW_DELETED）
Query q/code/status/deleted/page/page_size/sort/order；成功 200 列表响应（默认含未删除 ACTIVE 与 INACTIVE）；错误 401/403/422/500。

### 6.2 POST /api/v1/clusters — WRITE
Request：code(必填,§2.1)、name(必填,§2.2)、status(可选默认 ACTIVE)、description(可选 null)、metadata(可选默认 {})；未列/只读字段→422。成功 201 {"cluster":Cluster}；写 CREATE Audit。错误 401/403/409 CONFLICT{unique_conflict,field:"code"}/422/500。

### 6.3 GET /api/v1/clusters/{id} — READ
id=UUID（非 UUID 404）；Query deleted(bool 默认 false；true 需 VIEW_DELETED 否则 403)。成功 200；错误 401/403/404/500。

### 6.4 PATCH /api/v1/clusters/{id} — WRITE
Body（exclude_unset，省略=保持不重置）：version(必填 int≥1)、name(可选；显式 null→422)、status(可选；显式 null→422)、description(可选；显式 null 清空)、metadata(可选；整值替换；显式 null→422)；含 code 或只读字段→422。成功 200（version+1）；错误 401/403/404（不存在或已软删；已删不支持 PATCH）/409 VERSION_CONFLICT/422/500。校验顺序 401→403→body(422)→可见性(404)→版本(409)。

### 6.5 DELETE /api/v1/clusters/{id} — DELETE_OBJECT
Query version(必填 int≥1)；软删（置 deleted_at、version+1、updated_at）；不级联；引用检查（F003 空集）。成功 204；写 DELETE Audit。错误 401/403/404/409 VERSION_CONFLICT/409 CONFLICT{reference_exists,references}/422/500。顺序 401→403→对象(404)→version 校验(422)→版本(409)→引用(409)→软删。

### 6.6 POST /api/v1/clusters/{id}/restore — RESTORE（ADMIN）
Query version(必填)。置 deleted_at=null、version+1、updated_at；仅恢复自身不级联；重检唯一性与依赖（§21）。成功 200（deleted_at=null）；写 RESTORE Audit。错误 401/403/404（对象从不存在）/409 CONFLICT{not_deleted}/409 VERSION_CONFLICT/409 CONFLICT{unique_conflict|dependency_deleted}/422/500。顺序 401→403→查找(含软删,404)→未删则 409 not_deleted→版本(409)→依赖/唯一重检(409)→恢复。F003 说明：Cluster code_key 全量唯一恢复无 code 冲突自然路径；依赖检查器空集；两条 reason 为机制级，端到端归 F004+。

### 6.7 GET /api/v1/clusters/{id}/activity — VIEW_ACTIVITY（全角色）
Query deleted(bool 默认 false；已删需 true+VIEW_DELETED)、page/page_size。返回 (object_type="cluster",object_id=id) 审计按 created_at 升序、同刻 id 升序。成功 200 {items:[ActivityItem],page,page_size,total}；ActivityItem{id,action(enum),operator_user_id(UUID|null),operator_username(string),before_data(object|null),after_data(object|null),created_at}。只读，无审计修改/删除入口（§22）。错误 401/403/404/422/500。

## 7. 并发与错误语义小结

乐观锁：PATCH/DELETE/restore 条件 UPDATE WHERE id AND version=:expected SET version=version+1；rowcount=0→对象仍在则 409 VERSION_CONFLICT{current_version}，不可见/不存在则 404；无静默重试（§23/T26）。唯一性：创建冲突 409 CONFLICT{unique_conflict}；DB uq_clusters_code_key 兜底并发。删除/恢复冲突 409 CONFLICT。422=格式/字段非法；409=语义冲突。

## 8. Audit 一致性（D02 签核）

四类 action CREATE/UPDATE/DELETE/RESTORE 各写一行 audit_logs；同事务（AuditService.record 在业务 Service 内同 Session，一并 commit；异常一起 rollback，回滚不留 Audit，§22/A7）；快照走白名单 auditable_fields，不记 password/token/secret；object_type="cluster"、object_id=Cluster UUID（§4/A9）；Activity 按 (object_type,object_id) 过滤；完整跨对象审计归 F015/F016。

## 9. 业务边界

本 Feature 交付 Cluster 基础详情（§19 关联区域占位，F004+ 接入）；单对象恢复不级联；F003 引用集为空；未定义路径/方法 404/405；id 非 UUID 404。
