## 0. 通用约定

- 认证：HttpOnly Cookie `csm_session`（复用 F013，HTTP-only、无 `Secure`）。未认证 → `401 UNAUTHENTICATED`。
- 权限（服务端）：F003 全部端点（列表、详情）为**任意已登录**（`viewer`/`maintainer`/`admin`）可读；不设写权限。集群选择只改变查询作用域，不改变角色权限（§2.1、BQ-H）。
- 首登改密拦截由 F013 统一处理（`403 PASSWORD_CHANGE_REQUIRED`）。
- 分页（复用 F001/F005 约定）：`page`（int，默认 1，≥1）、`page_size`（int，默认 20，1–100）；返回 `total`。offset 分页（ADR-003）。
- 搜索口径（§8）：去首尾空格；英文不区分大小写；`%`、`_` 按普通字符处理；允许 IPv4 部分字符串；服务端全量匹配而非仅当前页。
- 展示文字（§6.2、§9.4）：类型/状态响应同时返回代码与中文展示文字（见 §1 映射）；状态不得只靠颜色。
- 普通列表仅返回仍存对象：真实删除即删行（`resources` 无软删列），故无需额外过滤；已删除对象仅存于资源历史（F012）。
- 时间字段为 `string(date-time)`（UTC），前端按时区显示（§9.4）。

### Problem+json（所有 4xx/5xx）
```json
{
  "type": "about:blank",
  "title": "string",
  "status": 400,
  "code": "INVALID_REQUEST",
  "message": "string",
  "errors": [
    { "field": "cluster_id", "code": "CLUSTER_ID_REQUIRED", "message": "资源列表必须指定当前集群作用域 cluster_id" }
  ]
}
```
`errors` 可空/缺省。

### 错误码总表（F003）
| code | HTTP | 语义 |
| --- | --- | --- |
| `INVALID_REQUEST` | 400 | 查询参数非法；`errors[].code` ∈ `CLUSTER_ID_REQUIRED`/`CLUSTER_ID_INVALID`/`RESOURCE_TYPE_INVALID`/`STATUS_INVALID`/`INVALID_SORT`/`INVALID_PAGE`/`INVALID_PAGE_SIZE` |
| `UNAUTHENTICATED` | 401 | 无有效会话 |
| `FORBIDDEN` | 403 | （仅全局拦截：如首登未改密 `PASSWORD_CHANGE_REQUIRED`；列表/详情本身对任意已登录可读，不因角色返回 403） |

> F003 列表为只读查询：空结果与不存在的 `cluster_id` 均返回 `200` 空列表（`PROPOSED`，与 F005 `GET` 列表一致），不返回 404。

## 1. Schema

### ClusterScope（列表作用域回显，只读）
| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| cluster_id | integer | 否 | 本次查询的集群作用域 ID |
| cluster_code | string | 否 | 集群展示编号（便利字段） |
| cluster_name | string | 否 | 集群名称（便利字段） |

> 用于前端显式展示「当前集群作用域」（§6.2：搜索 IP 时显示当前集群作用域）。

### ResourceListItem
| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| id | integer | 否 | 资源 ID（稳定标识） |
| name | string | 否 | 资源名称（去首尾空格） |
| cluster_id | integer | 否 | 所属集群 ID |
| cluster_code | string | 否 | 所属集群展示编号（便利字段） |
| cluster_name | string | 否 | 所属集群名称（便利字段） |
| resource_type | string | 否 | `bare_metal`/`virtual_machine` |
| resource_type_label | string | 否 | 展示文字：`裸金属`/`虚拟机`（`PROPOSED`） |
| status | string | 否 | `IDLE`/`ALLOC`/`DOWN`/`UNKNOWN` |
| status_label | string | 否 | 展示文字：`空闲`/`已分配`/`宕机`/`未知`（`PROPOSED`） |
| management_ip | ManagementIpSummary | 是 | 管理 IP；未指定 `null`（复用 `docs/api/F006.md` §1） |
| updated_at | string(date-time) | 否 | 资源更新时间 |

> `ManagementIpSummary` 字段：`ip_id`(integer)、`address`(string)、`interface_id`(integer)、`interface_name`(string)；见 `docs/api/F006.md` §1。
> CPU/vCPU/内存摘要列（§6.2）由 F004 在此列表项上扩展（附加字段），不在本 Feature。

### PagedResources
| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| items | ResourceListItem[] | 否（空为 `[]`） | 当前页数据 |
| total | integer | 否 | 当前集群作用域与过滤条件下匹配总数 |
| page | integer | 否 | 当前页 |
| page_size | integer | 否 | 每页条数 |
| scope | ClusterScope | 否 | 本次查询作用域回显 |

> 复用 F002/F006 `ResourceFormDetail` 作为资源详情响应（本文件不重复定义），见 `docs/api/F002.md` §1 与 `docs/api/F006.md` §1。

## 2. 端点

### 2.1 GET `/resources`
- 权限：任意已登录。
- 说明：计算资源统一列表（当前集群作用域、类型/状态筛选、名称与 IP 搜索、服务端分页、默认按名称排序）。新增端点；与 F002 `POST /resources` 同路径不同方法。
- Query：
  | 参数 | 类型 | 必填 | 默认 | 说明 |
  | --- | --- | --- | --- | --- |
  | cluster_id | integer | **是** | — | 当前集群作用域（§6.2）；缺失/非法 → `400 INVALID_REQUEST`（`CLUSTER_ID_REQUIRED`/`CLUSTER_ID_INVALID`）。`PROPOSED`：必填以强制作用域、避免隐式跨集群 |
  | resource_type | string | 否 | 全部 | `bare_metal`/`virtual_machine`；省略 = 全部（对应「全部/裸金属/虚拟机」切换） |
  | status | string | 否 | 全部 | `IDLE`/`ALLOC`/`DOWN`/`UNKNOWN`；省略 = 全部 |
  | q | string | 否 | — | 去首尾空格；匹配资源名称、资源 ID（纯数字）、本集群内该资源已登记 IPv4（部分，§8.1/§8.2）；空串 = 不搜索 |
  | page | integer | 否 | 1 | ≥1 |
  | page_size | integer | 否 | 20 | 1–100 |
  | sort | string | 否 | `name` | `name`/`-name`/`updated_at`/`-updated_at`/`created_at`/`-created_at`/`status`/`-status`；非法 → `400 INVALID_REQUEST`（`INVALID_SORT`） |
- 排序语义：无 `q` 时按 `sort`（默认 `name` 升序）+ `id` 升序稳定排序；有 `q` 时先按匹配权重（`PROPOSED`：名称/IP 完全匹配 > 名称/IP 前缀匹配 > 资源 ID 精确匹配 > 名称/IP 包含匹配），再按 `sort` + `id`。
- Response `200`：`PagedResources`。
- 错误：`401 UNAUTHENTICATED`；`400 INVALID_REQUEST`（`CLUSTER_ID_REQUIRED`/`CLUSTER_ID_INVALID`/`RESOURCE_TYPE_INVALID`/`STATUS_INVALID`/`INVALID_SORT`/`INVALID_PAGE`/`INVALID_PAGE_SIZE`）。
- 边界：
  - 集群内无匹配 → `200` + `items: []`、`total: 0`；
  - `cluster_id` 不存在 → `200` + `items: []`、`total: 0`（`PROPOSED`，筛选无结果不报 404）；
  - `page` 超出末页 → `200` + `items: []`、`total` 不变；
  - 资源管理 IP 未指定 → `management_ip: null`；
  - 仅返回 `cluster_id` 作用域内仍存资源，**不返回其它集群**（即使存在相同 IP/名称；场景 56 的当前集群侧）。

### 2.2 GET `/resources/{resource_id}`
- 权限：任意已登录。
- 说明：资源公共详情；**复用 `docs/api/F002.md` §2.2（F006 扩展）**，本文件不重定义字段与错误。详情页消费 `ResourceFormDetail`：名称、集群、类型、状态、状态来源操作者（`status_updated_by`/`status_updated_by_username`）、状态更新时间（`status_updated_at`）、更新时间（`updated_at`）、网卡（含 `ips`、`segment` 只读摘要）、管理 IP（`management_ip`）。
- 复用边界：无网卡 → `interfaces: []`；无 IP 网卡 → 该网卡 `ips: []`（场景 8）；无管理 IP → `management_ip: null`；资源不存在 → `404 RESOURCE_NOT_FOUND`。
- 扩展预留（`PROPOSED`，交 F004/F007）：类型专有字段（F004）与服务关联（F007）以附加字段扩展同一资源详情响应；本 Feature 仅使用上述公共字段。

## 3. 业务边界汇总

| 边界 | 结果 |
| --- | --- |
| 列表缺 `cluster_id` | `400 INVALID_REQUEST`（`CLUSTER_ID_REQUIRED`） |
| `cluster_id` 非法（非整数/≤0） | `400 INVALID_REQUEST`（`CLUSTER_ID_INVALID`） |
| `cluster_id` 不存在或集群内无资源 | `200` + `items: []`、`total: 0`（`PROPOSED`） |
| 类型/状态筛选省略 | 返回全部类型/状态 |
| 非法 `resource_type`/`status` | `400 INVALID_REQUEST` |
| 非法 `sort`/`page`/`page_size` | `400 INVALID_REQUEST` |
| 搜索按名称 | 部分匹配、英文不区分大小写、`%`/`_` 字面量 |
| 搜索按 IPv4 | 部分匹配；仅本集群内该资源已登记 IP |
| 跨集群存在相同 IP/名称 | 资源列表只返回本集群数据（全局 IP 查询属 F010） |
| 无 `q` 默认排序 | 按 `name` 升序，`id` 稳定次排序 |
| 有 `q` 排序 | 匹配权重优先，再按 `sort` + `id` |
| 资源管理 IP 未指定 | `management_ip: null` |
| 详情无 IP 网卡 | `interfaces[].ips: []`（合法，场景 8） |
| 详情资源不存在 | `404 RESOURCE_NOT_FOUND`（复用 F002） |
| 查看者/maintainer/admin 读 | 允许 |
| 未登录 | `401 UNAUTHENTICATED` |
| F003 新增/编辑/删除端点 | 无（写入归 F002/F006） |
