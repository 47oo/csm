# F005 网段、保留地址与网段历史写入 — API Contract

> Status: **READY**

> Feature: F005；依据 ADR-003（已批准 2026-09-25）、`requirements-v2.md` §4.4/§4.6/§5/§6.5/§8、§10 场景 10/11/12/53/60/82、BQ-M/BQ-N/BQ-O/BQ-R/BQ-W/BQ-Z

## 0. 通用约定

- 认证：HttpOnly Cookie `csm_session`（复用 F013，HTTP-only、无 `Secure`）。未认证 → `401 UNAUTHENTICATED`。
- 权限（服务端）：
  - 列表/详情/保留地址读取：任意已登录（`viewer`/`maintainer`/`admin`）；
  - 新增/编辑/保留地址增删/网关设置与清空：`maintainer`/`admin`；越权 → `403 FORBIDDEN`，数据不变；
  - 真实删除：`maintainer`/`admin`；越权 → `403 FORBIDDEN`。
- 首登改密拦截由 F013 统一处理（`403 PASSWORD_CHANGE_REQUIRED`）。
- CIDR 规范化：IPv4 CIDR 经 `ipaddress.IPv4Network(raw, strict=False)` 归一化为网络地址字符串（`cidr` 字段即 `cidr_key`）。IPv6 或非法 → `422`。
- 名称：去首尾空格后存储/比较，**区分大小写**，禁止纯空白；同集群仍存网段内唯一。
- 分页：`page`（int，默认 1，≥1）、`page_size`（int，默认 20，1–100）；返回 `total`。排序 `sort`，允许 `name`/`-name`/`cidr`/`-cidr`/`created_at`/`-created_at`，默认 `name`。
- 地址字段均为点分十进制 IPv4 字符串（如 `192.168.1.10`）；`null` 表示未设置。
- 计数为查询时快照（§5 BQ-R），非预占。

### Problem+json（所有 4xx/5xx）
```json
{
  "type": "about:blank",
  "title": "string",
  "status": 422,
  "code": "VALIDATION_ERROR",
  "message": "string",
  "errors": [
    { "field": "reserved_addresses[0].start_ip", "code": "RESERVED_OUT_OF_CIDR", "message": "保留地址超出所属网段 CIDR" }
  ]
}
```
`errors` 可空/缺省。

### 错误码总表

| `AUTO_RANGE_INVALID` | 422 | 自动分配范围非法（仅一端非空、越界或起 > 止）；亦作为 `errors[].code` |
| `RESERVED_OUT_OF_CIDR` | 422 | 保留地址/范围端点超出所属网段 CIDR；亦作为 `errors[].code` |

| `VERSION_CONFLICT` | 409 | 乐观锁冲突 |

## 2. 网段端点

### 2.1 GET `/network-segments`
- 权限：任意已登录。
- Query：
  | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | cluster_id | integer | 否 | 按所属集群筛选；省略则跨集群返回 |
  | page | integer | 否 | 默认 1 |
  | page_size | integer | 否 | 默认 20，1–100 |
  | q | string | 否 | 去首尾空格；匹配网段名称、CIDR、用途、技术类型（英文不区分大小写、包含匹配，`%`/`_` 按普通字符，§8.1）。`q` 非空时排序权重（完全 > 前缀 > 包含，同级按 `sort` 再 `id`）以 `docs/api/F008.md` §1 为准；本端点仅补充排序优先级，包含语义与默认 `sort` 不变 |
  | sort | string | 否 | 默认 `name` |
- Response `200`：`PagedNetworkSegments`。
- 边界：无匹配 → `200` + `items: []`、`total: 0`；`cluster_id` 不存在 → `200` + 空列表（筛选无结果，不报 404）。
- 错误：`401 UNAUTHENTICATED`；`400 INVALID_REQUEST`（非法 `sort`/`page_size`）。

### 2.2 POST `/network-segments`
- 权限：`maintainer`/`admin`。
- Request：
```json
{
  "cluster_id": 1,
  "name": "management",
  "cidr": "192.168.1.0/24",
  "purpose": "管理",
  "technology": "Ethernet",
  "vlan": 100,
  "gateway": "192.168.1.1",
  "auto_alloc_start": "192.168.1.20",
  "auto_alloc_end": "192.168.1.30"
}
```
  | 字段 | 类型 | 必填 | 校验 |
  | --- | --- | --- | --- |
  | cluster_id | integer | 是 | 集群须存在，否则 `404 CLUSTER_NOT_FOUND` |
  | name | string | 是 | 去首尾空格非空、区分大小写、同集群唯一 |
  | cidr | string | 是 | IPv4 CIDR；规范化后同集群唯一 |
  | purpose | string | 是 | 去首尾空格非空（表示见架构 §4.3） |
  | technology | string | 是 | 去首尾空格非空 |
  | vlan | integer\|null | 否 | `1–4094` |
  | gateway | string\|null | 否 | 必须落在 `cidr` 内 |
  | auto_alloc_start | string\|null | 否 | 与 `auto_alloc_end` 同为 null 或同为非空；非空须在 `cidr` 内且 ≤ end |
  | auto_alloc_end | string\|null | 否 | 同上 |
- Response `201`：`NetworkSegmentDetail`（含 `overlaps`/`has_overlap` 与计数）。
- 错误：`403 FORBIDDEN`；`404 CLUSTER_NOT_FOUND`；`409 SEGMENT_NAME_TAKEN`；`409 SEGMENT_CIDR_TAKEN`；`422 VALIDATION_ERROR`。
- 语义：写 `segment.create` 审计；同集群重叠仅提示、允许保存。

### 2.3 GET `/network-segments/{segment_id}`
- Path：`segment_id` integer。
- 权限：任意已登录。
- Response `200`：`NetworkSegmentDetail`。
- 错误：`404 SEGMENT_NOT_FOUND`；`401 UNAUTHENTICATED`。

### 2.4 PATCH `/network-segments/{segment_id}`
- 权限：`maintainer`/`admin`。
- Request（`version` 必填；省略的字段=不修改；`null` 表示显式清空可空字段）：
```json
{
  "name": "management",
  "cidr": "192.168.1.0/24",
  "purpose": "管理",
  "technology": "Ethernet",
  "vlan": 200,
  "gateway": "192.168.1.1",
  "auto_alloc_start": null,
  "auto_alloc_end": null,
  "version": 3
}
```
  | 字段 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | name | string | 否 | 同 POST 校验；省略=不修改 |
  | cidr | string | 否 | 省略=不修改；存在已分配 IP → `409 CIDR_IMMUTABLE`；新 CIDR 须容纳既有网关/自动范围/保留地址 |
  | purpose | string | 否 | 省略=不修改 |
  | technology | string | 否 | 省略=不修改 |
  | vlan | integer\|null | 否 | `null` 清空 |
  | gateway | string\|null | 否 | `null` 清空；非空须在（最终）CIDR 内 |
  | auto_alloc_start | string\|null | 否 | 与 `auto_alloc_end` 同时给出（同为 null 或同为非空） |
  | auto_alloc_end | string\|null | 否 | 同上 |
  | version | integer | 是 | 乐观锁 |
- Response `200`：`NetworkSegmentDetail`（`version` 已自增）。
- 错误：`400 INVALID_REQUEST`（无可改字段）；`403 FORBIDDEN`；`404 SEGMENT_NOT_FOUND`；`409 SEGMENT_NAME_TAKEN`/`SEGMENT_CIDR_TAKEN`/`CIDR_IMMUTABLE`/`VERSION_CONFLICT`；`422 VALIDATION_ERROR`（含 `GATEWAY_OUT_OF_CIDR`/`AUTO_RANGE_INVALID`/`RESERVED_OUT_OF_CIDR`）。
- 语义：同事务锁定行、校验、更新、写 `segment.update` 审计与 `resource_history(update)`。

### 2.5 DELETE `/network-segments/{segment_id}`
- 权限：`maintainer`/`admin`。
- Query：
  | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | confirm | string | 是 | 二次确认：去首尾空格后须等于网段名称（区分大小写） |
  | version | integer | 是 | 乐观锁 |
- Response `204`。
- 错误：`404 SEGMENT_NOT_FOUND`；`422 DELETE_CONFIRMATION_MISMATCH`（不执行删除）；`409 SEGMENT_HAS_ALLOCATIONS`/`SEGMENT_HAS_RESERVED_ADDRESSES`/`SEGMENT_HAS_INTERFACES`/`SEGMENT_GATEWAY_NOT_CLEARED`/`VERSION_CONFLICT`；`403 FORBIDDEN`。
- 语义：真实删除、无恢复入口、不级联；删除前同事务写 `segment.delete` 审计与 `resource_history(delete)`；历史保留。
- 校验顺序（建议）：`401/403` → `404` → `422`（确认不匹配）→ `409`（保留地址/网关）→ `DELETE ... WHERE id AND version` → `23503` 映射（已分配 IP/网卡引用）→ rowcount 0 → `404`/`409 VERSION_CONFLICT`。

## 3. 保留地址与网关端点

### 3.1 GET `/network-segments/{segment_id}/reserved-addresses`
- 权限：任意已登录。
- Response `200`：`ReservedAddressList`（按 `start_ip` 升序）。
- 错误：`404 SEGMENT_NOT_FOUND`；`401 UNAUTHENTICATED`。

### 3.2 POST `/network-segments/{segment_id}/reserved-addresses`
- 权限：`maintainer`/`admin`。
- Request：
```json
{ "start_ip": "192.168.1.100", "end_ip": "192.168.1.110" }
```
  | 字段 | 类型 | 必填 | 校验 |
  | --- | --- | --- | --- |
  | start_ip | string | 是 | IPv4；须在所属网段 CIDR 内 |
  | end_ip | string\|null | 否 | 省略或 `null` 表示单地址（= `start_ip`）；非空须在 CIDR 内且 ≥ `start_ip` |
- Response `201`：`ReservedAddress`。
- 错误：`403 FORBIDDEN`；`404 SEGMENT_NOT_FOUND`；`422 VALIDATION_ERROR`（`RESERVED_OUT_OF_CIDR`/`RESERVED_RANGE_INVALID`/`RESERVED_OVERLAP`）。
- 语义：事务内锁定父网段校验；写 `segment.reserved_address.create` 审计与 `resource_history(update)`；不改变网段 `version`（PROPOSED）。

### 3.3 DELETE `/network-segments/{segment_id}/reserved-addresses/{reserved_id}`
- 权限：`maintainer`/`admin`。
- Path：`segment_id`、`reserved_id` integer。
- Response `204`。
- 错误：`403 FORBIDDEN`；`404 SEGMENT_NOT_FOUND` / `RESERVED_ADDRESS_NOT_FOUND`。
- 语义：逐条真实删除、无恢复；写 `segment.reserved_address.delete` 审计与 `resource_history(update)`；不改变网段 `version`（PROPOSED）。

### 3.4 DELETE `/network-segments/{segment_id}/gateway`
- 权限：`maintainer`/`admin`。
- Query：
  | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | version | integer | 是 | 乐观锁 |
- Response `204`（幂等：网关已为空仍返回 `204`）。
- 错误：`403 FORBIDDEN`；`404 SEGMENT_NOT_FOUND`；`409 VERSION_CONFLICT`。
- 语义：显式清空网关（§4.4/§5 删除前置）；写 `segment.gateway.clear` 审计与 `resource_history(update)`；`version` 自增。
- 说明：`PATCH` 传 `"gateway": null` 亦可清空；本端点提供显式语义与乐观锁。

## 4. 业务边界汇总

| 边界 | 结果 |
| --- | --- |
| 空网段列表 | `200`，`items: []`，`total: 0` |
| 不存在的网段（详情/编辑/删除/保留地址） | `404 SEGMENT_NOT_FOUND` |
| 新增时 `cluster_id` 不存在 | `404 CLUSTER_NOT_FOUND` |
| 同集群网段名称重复（区分大小写） | `409 SEGMENT_NAME_TAKEN` |
| 跨集群同名 | 允许 |
| 同集群规范化 CIDR 重复（含主机位归一化后相同） | `409 SEGMENT_CIDR_TAKEN` |
| 跨集群相同 CIDR | 允许 |
| 同集群网段重叠（CIDR 不等） | 保存成功，返回 `overlaps`/`has_overlap`（仅提示） |
| CIDR 非法 / IPv6 | `422 VALIDATION_ERROR`（`CIDR_INVALID`/`CIDR_NOT_IPV4`） |
| 保留地址/范围端点、网关超出 CIDR | `422`（`RESERVED_OUT_OF_CIDR`/`GATEWAY_OUT_OF_CIDR`），原配置不变 |
| 自动分配范围仅一端非空 / 越界 / 起 > 止 | `422`（`AUTO_RANGE_INVALID`） |
| 同一网段保留范围重叠/重复 | `422`（`RESERVED_OVERLAP`） |
| 存在已分配 IP 时修改 CIDR | `409 CIDR_IMMUTABLE`（F006 生效） |
| 真实删除时有保留地址 | `409 SEGMENT_HAS_RESERVED_ADDRESSES` |
| 真实删除时网关未清空 | `409 SEGMENT_GATEWAY_NOT_CLEARED` |
| 新增保留地址与同集群既有已分配 IP 冲突 | `409 RESERVED_ADDRESS_CONFLICTS_ALLOCATION`（F006 引入分配后生效） |
| 设置/修改网关与同集群既有已分配 IP 冲突 | `409 GATEWAY_CONFLICTS_ALLOCATION`（F006 引入分配后生效） |
| 真实删除时有已分配 IP | `409 SEGMENT_HAS_ALLOCATIONS`（F006 引入） |
| 真实删除时仍被网卡引用 | `409 SEGMENT_HAS_INTERFACES`（F002 引入） |
| `confirm` 不匹配网段名称 | `422 DELETE_CONFIRMATION_MISMATCH`，不删除 |
| 查看者调用写/删 | `403 FORBIDDEN`，数据不变 |
| 并发编辑/删除 | `409 VERSION_CONFLICT`，前端保留输入 |
| 未登录访问受保护端点 | `401 UNAUTHENTICATED` |

## 5. 说明
- 本 Contract 只描述 API 字段与错误语义，不新增业务规则；规则以 `docs/product/requirements-v2.md` §4.4/§4.6/§5/§6.5 为准。
- `allocated_count` 在 F005 阶段恒为 `0`；「已分配 IP 及归属」列表为 `NOT_REQUIRED`（由 F006 交付）。
- 已分配 IP 相关的删除拒绝（`SEGMENT_HAS_ALLOCATIONS`）与 CIDR 不可修改（`CIDR_IMMUTABLE`）由 F006 引入引用后验收；网卡引用拒绝（`SEGMENT_HAS_INTERFACES`）由 F002 引入引用后验收。
- 资源历史查询（F012）、聚合计数（F010）不在本 Contract。
- `RESERVED_ADDRESS_CONFLICTS_ALLOCATION`/`GATEWAY_CONFLICTS_ALLOCATION` 在 F006 引入真实 IP 分配后生效：新增保留地址或设置/修改网关时，若与同集群既有已分配 IP（含重叠网段、跨网段）冲突则拒绝且原配置不变（§5、场景 26/27/52）。
