## 0. 通用约定（增量）

- 认证/权限：沿用 F002 §0。IP 与管理 IP 的读写发生在 `/resources` 端点内，鉴权同 F002；查看者只读。
- 整单原子（§4.5）：一次请求提交公共信息 + 全部网卡 + 全部 IP，单事务；任一失败整单不生效。
- IP 显式操作（ADR-003）：编辑时 `interfaces[]` 的 `ips[]` 每项须声明 `op ∈ {create, delete}`；**未列入 `ips[]` 的既有 IP 视为未修改**；**禁止改写 IP 地址**（改址＝删除后重新分配）。
- 记录级错误定位：`errors[].field` 支持数组下标（如 `interfaces[1].ips[0].address`），下标 0 基；`interfaces[i]` 指请求 `interfaces[]` 的第 i 项。
- 地址字段为点分十进制 IPv4 字符串（如 `192.168.1.10`），仅 IPv4。
- 管理 IP：资源引用字段，`nullable`；被引用 IP 必须属于本资源（§4.2.9）。
- 可分配性只以平台记录为准，不做网络探测（§5）。

### Problem+json（所有 4xx/5xx）
```json
{
  "type": "about:blank",
  "title": "string",
  "status": 409,
  "code": "IP_ALREADY_IN_USE",
  "message": "string",
  "errors": [
    { "field": "interfaces[1].ips[0].address", "code": "IP_ALREADY_IN_USE", "message": "10.0.0.1 已被本集群 cn002/ib0 使用" }
  ],
  "conflicts": [
    { "ip": "10.0.0.1", "resource_id": 7, "resource_name": "cn002", "interface_id": 12, "interface_name": "ib0" }
  ]
}
```
- `errors` 可空/缺省；扩展成员 `conflicts`（数组，可缺省）用于 `IP_ALREADY_IN_USE`，供前端展示「已被本集群 X/Y 使用」（§7.3）。

### 错误码（F006 新增/扩展）
| code | HTTP | 语义 |
| --- | --- | --- |
| `VALIDATION_ERROR` | 422 | 字段级校验失败；`errors[].code` 含本表寄存器项（见下） |
| `IP_INVALID` | 422 | IPv4 语法/语义非法（`errors[].code`） |
| `IP_OUT_OF_SEGMENT` | 422 | 地址不在网卡所选网段 CIDR 内（`errors[].code`） |
| `IP_RESERVED` | 422 | 地址命中仍存网段保留地址（`errors[].code`） |
| `IP_GATEWAY` | 422 | 地址命中仍存网段网关（`errors[].code`） |
| `IP_NETWORK_ADDRESS` | 422 | 普通网段网络地址（`errors[].code`） |
| `IP_BROADCAST_ADDRESS` | 422 | 普通网段广播地址（`errors[].code`） |
| `SEGMENT_NOT_SELECTED` | 422 | 未选网段即分配 IP（`errors[].code`） |
| `AUTO_RANGE_NOT_ENABLED` | 422 | 自动分配但网段未启用自动范围（`errors[].code`） |
| `INTERFACE_SEGMENT_CHANGE_REQUIRES_IP_RELEASE` | 422 | 改网段但该网卡仍有 IP 未释放（`errors[].code`） |
| `MANAGEMENT_IP_INVALID` | 422 | 管理 IP 引用不解析为本资源有效 IP |
| `MANAGEMENT_IP_REQUIRED` | 422 | 删除管理 IP 或其网卡但未显式清空/重选 |
| `IP_NOT_FOUND` | 422 | `ips[]` `delete` 的 `id` 不属于该网卡/资源（`errors[].code`） |
| `IP_ALREADY_IN_USE` | 409 | 同集群地址已被占用（含并发）；附 `conflicts` |
| `NO_AVAILABLE_ADDRESS` | 409 | 自动范围无可用地址；不切换网段 |
| `INTERFACE_HAS_IPS` | 409 | 删除网卡时仍有 IP 未逐项删除 |
| `CIDR_IMMUTABLE` | 409 | 存在已分配 IP 时禁止修改网段 CIDR（F005 端点，F006 生效） |
| `SEGMENT_HAS_ALLOCATIONS` | 409 | 网段仍有已分配 IP，禁止删除（F005 端点，F006 引入） |
| `RESERVED_ADDRESS_CONFLICTS_ALLOCATION` | 409 | 新增保留地址与同集群既有分配冲突（F005 端点扩展） |
| `GATEWAY_CONFLICTS_ALLOCATION` | 409 | 修改/设置网关与同集群既有分配冲突（F005 端点扩展） |
| `VERSION_CONFLICT` | 409 | 乐观锁冲突（沿用 F002/F005） |

> 错误码命名为 `PROPOSED`；如与实现评审冲突可调整，但语义与状态不得改变产品规则。

## 2. 资源端点扩展（权威基础见 `docs/api/F002.md`）

### 2.1 POST `/resources`
- 权限：`maintainer`/`admin`。
- Request（在 F002 基础上扩展 `interfaces[].ips` 与顶层 `management_ip`）：
```json
{
  "cluster_id": 1,
  "name": "cn001",
  "resource_type": "bare_metal",
  "status": "ALLOC",
  "interfaces": [
    {
      "name": "eth0",
      "segment_id": 3,
      "ips": [
        { "mode": "manual", "address": "192.168.1.10" },
        { "mode": "auto" }
      ]
    },
    { "name": "ib0", "segment_id": null, "ips": [] }
  ],
  "management_ip": { "interface_index": 0, "address": "192.168.1.10" }
}
```
  | 字段 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | （F002 既有 cluster_id/name/resource_type/status/interfaces 不变） | — | — | — |
  | interfaces[].ips | IpCreate[] | 否 | 缺省 `[]`；需 `segment_id` 非空 |
  | management_ip | ManagementIpRef\|null | 否 | 省略/`null` = 无管理 IP |
- Response `201`：`ResourceFormDetail`（含 `interfaces[].ips` 与 `management_ip`）。
- 错误：F002 全部错误码，另加 `409 IP_ALREADY_IN_USE`（附 `conflicts`）、`409 NO_AVAILABLE_ADDRESS`、`422 VALIDATION_ERROR`（`IP_OUT_OF_SEGMENT`/`IP_RESERVED`/`IP_GATEWAY`/`IP_NETWORK_ADDRESS`/`IP_BROADCAST_ADDRESS`/`SEGMENT_NOT_SELECTED`/`AUTO_RANGE_NOT_ENABLED`/`MANAGEMENT_IP_INVALID`）。
- 语义：单事务创建资源 + 全部网卡 + 全部 IP + 管理 IP；IP 排除 §5 全部条件；写 `resource.create` 审计。

### 2.2 GET `/resources/{resource_id}`
- 权限：任意已登录。
- Response `200`：`ResourceFormDetail`（含 `interfaces[].ips` 与管理 IP）。
- 错误：`404 RESOURCE_NOT_FOUND`；`401 UNAUTHENTICATED`。
- 边界：网卡无 IP → `ips: []`；无管理 IP → `management_ip: null`；IP 按地址数值升序。

### 2.3 PATCH `/resources/{resource_id}`
- 权限：`maintainer`/`admin`。
- Request（在 F002 基础上扩展 `interfaces[].ips`、顶层 `management_ip`；`version` 必填）：
```json
{
  "interfaces": [
    {
      "op": "update",
      "id": 10,
      "segment_id": 3,
      "ips": [
        { "op": "delete", "id": 55 },
        { "op": "create", "mode": "auto" }
      ]
    },
    { "op": "create", "name": "ib1", "segment_id": 4, "ips": [{ "op": "create", "mode": "manual", "address": "10.0.0.7" }] },
    { "op": "delete", "id": 11, "ips": [{ "op": "delete", "id": 60 }] }
  ],
  "management_ip": { "interface_index": 0, "address": "192.168.1.20" },
  "version": 3
}
```
  | 字段 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | （F002 既有 name/status/interfaces/version 不变） | — | — | — |
  | interfaces[].ips | IpOp[] | 否 | `delete`/`create` 显式操作；未列出=未修改 |
  | management_ip | ManagementIpRef\|null | 否 | 省略=不修改；`null`=清空；否则重选；删除当前管理 IP/其网卡而未给出 → `MANAGEMENT_IP_REQUIRED` |
- Response `200`：`ResourceFormDetail`（`version` 自增）。
- 错误：F002 全部错误码，另加 `409 IP_ALREADY_IN_USE`/`NO_AVAILABLE_ADDRESS`/`INTERFACE_HAS_IPS`、`422 VALIDATION_ERROR`（`IP_OUT_OF_SEGMENT`/`IP_RESERVED`/`IP_GATEWAY`/`IP_NETWORK_ADDRESS`/`IP_BROADCAST_ADDRESS`/`SEGMENT_NOT_SELECTED`/`AUTO_RANGE_NOT_ENABLED`/`INTERFACE_SEGMENT_CHANGE_REQUIRES_IP_RELEASE`/`MANAGEMENT_IP_INVALID`/`MANAGEMENT_IP_REQUIRED`/`IP_NOT_FOUND`）。
- 语义：单事务应用公共信息、网卡与 IP 显式增/删、管理 IP 清空/重选；任一失败整单回滚（场景 43）；未修改的既有 IP 不被当作冲突（场景 44）；写 `resource.update` 审计与 `resource_history(update)`；重复提交未改变字段仍按一次变更（BQ-AC）。
- 边界：`ips` 中同时出现同地址 `delete` 与 `create`（换网卡/同网卡重分配）由事务顺序与可延迟唯一约束处理（实现）；`delete` 不存在的 `id` → `IP_NOT_FOUND`。

### 2.4 DELETE `/resources/{resource_id}`
- 沿用 F002：`confirm`/`version`；须先逐项删除全部网卡（进而 IP）。
- 错误：F002 全部，另加网卡仍有 IP 时阻止删除网卡的 `409 INTERFACE_HAS_IPS`（发生在 PATCH，不在 DELETE 本端点）。

## 3. 网段已分配 IP 端点（新增）

### 3.1 GET `/network-segments/{segment_id}/allocated-ips`
- 权限：任意已登录。
- Path：`segment_id` integer。
- Query：
  | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- |
  | page | integer | 否 | 默认 1，≥1 |
  | page_size | integer | 否 | 默认 20，1–100 |
  | q | string | 否 | 去首尾空格；匹配地址、资源名、接口名（英文不区分大小写、包含匹配，§8） |
- Response `200`：`PagedAllocatedIps`（按地址数值升序）。
- 错误：`404 SEGMENT_NOT_FOUND`；`401 UNAUTHENTICATED`；`400 INVALID_REQUEST`（非法 `page_size`）。
- 边界：无已分配 IP → `200` + `items: []`、`total: 0`。
- 说明：为 F005 §7.3「已分配 IP 及归属」页签数据源；F005 `allocated_count` 与 `auto_assignable_count` 随之由 F006 真实计算。

## 4. F005 端点扩展（F006 提供分配冲突检查）

> 以下错误码作用于 `docs/api/F005.md` 的既有端点；F006 提供同集群已分配集合查询。**需协调器同步修订 `docs/api/F005.md`**（附加错误码，不改既有语义）。规则依据 §5、场景 27/52。

- `POST /network-segments/{segment_id}/reserved-addresses`：若新增保留范围与同集群既有分配地址（含重叠网段、跨网段）取交集非空 → `409 RESERVED_ADDRESS_CONFLICTS_ALLOCATION`，原配置不变。
- `PATCH /network-segments/{segment_id}`：若将 `gateway` 设为落在本集群既有分配地址上的值 → `409 GATEWAY_CONFLICTS_ALLOCATION`，原配置不变；同时存在已分配 IP 时修改 `cidr` → `409 CIDR_IMMUTABLE`。
- `DELETE /network-segments/{segment_id}`：仍有已分配 IP → `409 SEGMENT_HAS_ALLOCATIONS`。
- `GET /network-segments/{segment_id}` 与列表的 `allocated_count`/`auto_assignable_count`：接入 F006 真实查询后返回非零实际值；`auto_assignable_count` 扣除同集群已分配地址（扫描时快照，非预占，场景 65）。

## 5. 业务边界汇总

| 边界 | 结果 |
| --- | --- |
| 未选网段即分配 IP | `422 SEGMENT_NOT_SELECTED` |
| 地址越出所选网段 | `422 IP_OUT_OF_SEGMENT` |
| 同集群重复 IPv4（含并发） | `409 IP_ALREADY_IN_USE`，附 `conflicts`；跨集群允许 |
| 命中仍存网段保留/网关 | `422 IP_RESERVED` / `IP_GATEWAY` |
| 普通网段网络/广播地址 | `422 IP_NETWORK_ADDRESS` / `IP_BROADCAST_ADDRESS` |
| 自动范围未启用却请求自动 | `422 AUTO_RANGE_NOT_ENABLED` |
| 自动范围耗尽 | `409 NO_AVAILABLE_ADDRESS`，不切换网段 |
| 改网段但仍有 IP | `422 INTERFACE_SEGMENT_CHANGE_REQUIRES_IP_RELEASE` |
| 删网卡但仍有 IP | `409 INTERFACE_HAS_IPS`，不级联 |
| `ips[]` `delete` 的 `id` 不属于该网卡 | `422 IP_NOT_FOUND` |
| 删管理 IP/其网卡未显式清空/重选 | `422 MANAGEMENT_IP_REQUIRED` |
| 管理 IP 引用非本资源 IP | `422 MANAGEMENT_IP_INVALID` |
| 资源无管理 IP | `management_ip: null`（合法） |
| 资源无 IP | `interfaces[].ips: []`（合法） |
| 重复提交未改变任何字段 | 按一次变更处理（`version` 递增、写历史），不短路（BQ-AC） |
| 存在已分配 IP 时改网段 CIDR | `409 CIDR_IMMUTABLE` |
| 有已分配 IP 时删网段 | `409 SEGMENT_HAS_ALLOCATIONS` |
| 新增保留/改网关与既有分配冲突 | `409 RESERVED_ADDRESS_CONFLICTS_ALLOCATION` / `GATEWAY_CONFLICTS_ALLOCATION` |
| 并发编辑（旧 version） | `409 VERSION_CONFLICT`，前端保留输入 |
| 查看者写/删 | `403 FORBIDDEN`，数据不变 |
| 未登录受保护端点 | `401 UNAUTHENTICATED` |
