## 1. 通用约定

- Base path /api/v1（§25），挂载同一 api_v1_router；路径 /api/v1/interfaces。
- 认证：csm_session HttpOnly Cookie（复用 F002 DR-08）；未认证先于权限返回 401。
- 时间：ISO-8601 UTC（D01 §2）。
- 操作者：服务端从 request.state.operator 取，写 Audit 的 operator_user_id+operator_username 快照（§22）；请求体不接受操作者字段。
- CSRF：不安全方法沿用 F002 §2.1；GET/HEAD 不校验。
- Interface 为**独立可寻址对象**（自身 UUID/version/软删/恢复/Activity），不并入 F004 嵌套（DR-84）。resource 归属只读、创建必填（DR-79）。

### 1.1 统一错误信封（复用 F002 §1.1）
`{ "error": { "code": "STRING_CODE", "message": "human readable", "details": {} } }`

### 1.2 错误码与 HTTP 映射（复用 F002 集 + F003 CONFLICT）

| HTTP | code | 触发 | details |
| --- | --- | --- | --- |
| 401 | AUTH_REQUIRED | 无有效会话 | {} |
| 403 | FORBIDDEN | 缺权限 / CSRF | {"reason":"permission"\|"csrf"} |
| 404 | NOT_FOUND | 不存在；或已软删且无 VIEW_DELETED；或未定义路径 | {} |
| 409 | VERSION_CONFLICT | 乐观锁过期 | {"current_version": int} |
| 409 | CONFLICT | 唯一/引用/恢复冲突 | 见下表 |
| 422 | VALIDATION_ERROR | 请求体/查询参数校验失败 | {"fields":[{"field":str,"message":str}]} |
| 500 | INTERNAL_ERROR | 未预期错误 | {} |

CONFLICT details.reason 枚举（复用 F003；F007 不新增 code）：

| reason | 场景 | 附加字段 |
| --- | --- | --- |
| unique_conflict | 同 Resource 未删 name 冲突（创建/PATCH/恢复重检） | field:"name" |
| not_deleted | 对未软删对象 restore | {} |
| dependency_deleted | 恢复重检：所属 Resource 仍软删/缺失，或 parent 失效 | conflicts:[{object_type:"resource"\|"interface", object_id}] |
| reference_exists | 删除 Interface 被未删对象引用（子 Interface / F010 IPAddress） | references:[{object_type,object_id,label}] |

错误码注册表以 docs/api/F002.md §1.2 为共享权威；F007 复用 F003 CONFLICT，不新增。

### 1.3 权限（§23，复用 F002 §3）
列表/详情=READ；创建/更新=WRITE；删除=DELETE_OBJECT；查看已删除（deleted=include|only、详情 deleted=true）=VIEW_DELETED；恢复=RESTORE；Activity=VIEW_ACTIVITY（全角色）。服务端执行；前端隐藏不替代；未认证先于权限→401。

## 2. 字段契约与归一化

### 2.1 Interface name（§4.1/§10，D01 §5.6，DR-73）
服务端 trim 首尾空白 → trim 后非空 → 禁内部空白（Unicode White_Space）与控制字符（Cc/Cf，应用层；DB 为 ASCII backstop）→ 长度（Unicode code point）1–64。**区分大小写、保留输入大小写、不折叠**（eth0 与 ETH0 为不同名称）。唯一：同 Resource **部分唯一** (resource_id,name) WHERE deleted_at IS NULL；软删后可复用；恢复重检冲突不覆盖新对象。不建独立归一化键列（DR-73）。

### 2.2 其它字段
- resource：创建必填，接受 Resource UUID；引用须存在、未软删，否则 422 field="resource"；**创建后不可改**（PATCH 出现含同值→422）。
- interface_type：可选默认 OTHER；∈{PHYSICAL,VIRTUAL,BOND,BRIDGE,VLAN,LOOPBACK,OTHER}；**不据 name 推断**；显式 null/非法→422。
- mac_address：可选 nullable；trim 后非空或 null；长度 ≤64 code point；**无格式正则、保留大小写、一期无全局唯一**；空串/纯空白→422（不转 null）。
- speed_mbps：可选 nullable；正整数或 null（1..2147483647）；0/负/超限/非整数→422；标称速率非实时。
- mtu：可选 nullable；正整数或 null（1..2147483647）；0/负/超限/非整数→422；单位字节，未知存 null 不转 0。
- parent_interface：可选 nullable UUID；须属于同 Resource、不能指向自身、不能形成循环；显式 null 清空为根。
- enabled：可选默认 true；boolean；显式 null→422；登记状态非实时探测。
- description：可选 nullable 文本。
- metadata：可选默认 {}；必须 JSON object；整值替换；显式 null/非 object→422。**Interface 自有**（DR-83）。
- version：int≥1；创建默认 1；PATCH/DELETE/restore 必填。

### 2.3 长度/数值口径（镜像 D01 v6 §5.6 与 DB）
name 1–64；mac_address ≤64；speed_mbps/mtu 1..2147483647；metadata JSON object。错误 fields[].field 用点路径，如 parent_interface、resource、interface_type、metadata。

### 2.4 省略语义（D01 §4）
创建省略非必填→默认/null；PATCH 字段省略=保持不重置；显式 null 仅清空 nullable（mac_address/speed_mbps/mtu/parent_interface/description）；必填/非 nullable 显式 null（name/interface_type/enabled/resource）→422；不可变 resource/只读字段出现在请求体→422；未知字段→422。

| 字段 | 类型 | nullable | 说明 |

| id | string(UUID) | 否 | 稳定 ID |
| resource | object{id,hostname} | 否 | 所属 Resource 嵌套展开 |
| name | string | 否 | 区分大小写保留输入（§2.1） |
| interface_type | enum | 否 | 7 值，默认 OTHER |
| mac_address | string | 是 | 未设置 null |
| speed_mbps | int | 是 | 未设置 null |
| mtu | int | 是 | 未设置 null |
| parent_interface | object{id,name}\|null | 是 | 无父接口 null |
| enabled | bool | 否 | 默认 true |
| description | string | 是 | 未设置 null |
| metadata | object | 否 | 默认 {}；整值替换 |

## 4. 分页/排序/过滤
分页 page≥1 默认 1；page_size 1–100 默认 20；越界/非整数→422。排序 sort∈{name,interface_type,speed_mbps,mtu,created_at,updated_at} 默认 created_at；order∈{asc,desc} 默认 desc；非法→422；附 id 升序稳定；sort=name 按区分大小写原值。过滤（AND）：resource_id=UUID（非 UUID→422；不存在→空结果）；interface_type∈7 值（非法→422）；enabled=bool（非法→422）；q=对 name 的**大小写敏感子串**（特殊字符按字面量转义，空/纯空白视为未提供；不用 pg_trgm）；parent_interface_id=UUID（非 UUID→422；不存在→空结果）；deleted∈{exclude,include,only} 默认 exclude。未列出参数忽略；条件仅作用于可见集合。

## 5. 软删可见性
列表 deleted∈{exclude,include,only} 默认 exclude；非法 422；include/only 需 VIEW_DELETED 否则 403 FORBIDDEN{reason:"permission"}。详情默认不可见软删对象；?deleted=true 需 VIEW_DELETED 否则 403；默认视图下软删返回 404（不泄露存在性）。Activity 对已删同理。

## 6. Endpoints

### 6.1 GET /api/v1/interfaces — READ（deleted=include|only 另需 VIEW_DELETED）
Query resource_id/interface_type/enabled/q/parent_interface_id/deleted/page/page_size/sort/order（§4）。成功 200 列表。错误 401/403/422/500。

### 6.2 POST /api/v1/interfaces — WRITE
Request：resource(必填 UUID)、name(必填 §2.1)、interface_type(可选默认 OTHER)、mac_address(可选 null)、speed_mbps(可选 null)、mtu(可选 null)、parent_interface(可选 null)、enabled(可选默认 true)、description(可选 null)、metadata(可选默认 {})；未列/只读字段→422。成功 201 {"interface":Interface}；同事务写 CREATE Audit。
错误：401/403 / 409 CONFLICT{unique_conflict,field:"name"} / 422（body 非法、resource 缺失/不存在/软删 field="resource"、parent 跨 Resource/自引用/成环 field="parent_interface"）/ 500。
**校验顺序**：401→403→body(422)→resource(422)→parent(422)→name 唯一(409)→写+Audit→201。

### 6.3 GET /api/v1/interfaces/{id} — READ
id=UUID（非 UUID→404）；Query deleted(bool 默认 false；true 需 VIEW_DELETED 否则 403)。成功 200 {"interface":Interface}。错误 401/403/404/500。

### 6.4 PATCH /api/v1/interfaces/{id} — WRITE
Body（exclude_unset，省略=保持；含 version 必填 int≥1）：name(可选，改后重检唯一)、interface_type(可选；显式 null→422)、mac_address(可选；显式 null 清空)、speed_mbps(可选；显式 null 清空)、mtu(可选；显式 null 清空)、parent_interface(可选；显式 null 清空为根；变更时重检同 Resource/无环)、enabled(可选；显式 null→422)、description(可选；显式 null 清空)、metadata(可选；整值替换；显式 null/非 object→422)；含 resource/id/只读字段→422。
成功 200 {"interface":Interface}；version+1；写 UPDATE Audit（before/after）。
错误：401/403/404（不存在或已软删）/ 409 VERSION_CONFLICT / 409 CONFLICT{unique_conflict,field:"name"} / 422（body/parent/不可变）。
**校验顺序**：401→403→body(422)→可见性(404)→parent 变更(422)→version(409)→name 唯一(409)→写+Audit→200。

### 6.5 DELETE /api/v1/interfaces/{id} — DELETE_OBJECT
Query version(必填 int≥1)。软删（置 deleted_at、version+1、updated_at）；不级联；引用检查：①存在未删子 Interface→409 CONFLICT{reference_exists,references:[{object_type:"interface",object_id,label:<子 name>}]}（DR-80）；②F010 未删 IPAddress 引用（F007 前为空集）→409 reference_exists，references 含 {object_type:"ip_address",object_id,label}（DR-82 预留）。成功 204；写 DELETE Audit。
错误 401/403/404/409 VERSION_CONFLICT/409 CONFLICT{reference_exists}/422/500。
**顺序**：401→403→对象(404)→version 校验(422)→版本(409)→引用(409)→软删。

### 6.6 POST /api/v1/interfaces/{id}/restore — RESTORE
Query version(必填 int≥1)。置 deleted_at=null、version+1、updated_at；仅恢复自身不级联；重检（§21）：name 同 Resource 未删唯一、所属 Resource 未软删、parent 有效（存在/同 Resource/未软删/无环）。失败不覆盖新对象。成功 200；写 RESTORE Audit。
错误 401/403 / 404（从未存在或调用者无 VIEW_DELETED）/ 409 CONFLICT{not_deleted} / 409 VERSION_CONFLICT / 409 CONFLICT{unique_conflict,field:"name"} / 409 CONFLICT{dependency_deleted,conflicts:[{object_type:"resource"|"interface",object_id}]} / 422 / 500。
**顺序**：401→403→查找(含软删,404)→未删则 409 not_deleted→版本(409)→name 唯一(409)→resource 依赖(409)→parent 依赖(409)→恢复。**name 复用优先于依赖失效**。

### 6.7 GET /api/v1/interfaces/{id}/activity — VIEW_ACTIVITY（全角色）
Query deleted(bool 默认 false；已删需 true+VIEW_DELETED)、page/page_size。返回 (object_type="interface",object_id=id) 审计 created_at 升序、同刻 id 升序。成功 200 {items:[ActivityItem],page,page_size,total}；ActivityItem{id,action(CREATE|UPDATE|DELETE|RESTORE),operator_user_id(UUID|null),operator_username,string,before_data(object|null),after_data(object|null),created_at}。只读无修改/删除入口（§22）。错误 401/403/404/422/500。

## 7. 并发与错误语义小结
乐观锁条件 UPDATE WHERE id AND version=:expected SET version=version+1；rowcount=0→对象仍可见则 409 VERSION_CONFLICT{current_version}，不可见/不存在则 404；无静默重试。唯一：创建/改名/恢复冲突 409 CONFLICT{unique_conflict,field:"name"}；DB uq_interfaces_resource_id_name 部分唯一兜底并发。删除/恢复冲突 409 CONFLICT。parent 环并发：应用事务内对目标 Resource 行 SELECT ... FOR UPDATE（复用 DR-71）串行化同 Resource 父变更 + 递归祖先校验（主）+ DB trg_interfaces_parent_valid 兜底（DR-85）；纯触发器无法单独闭并发窗口。422=格式/字段/形状非法；409=语义冲突。

## 8. Audit 一致性（§22）
四类 action 各写一行 audit_logs；同事务（业务 Service 内同 Session 一并 commit，异常一起 rollback，回滚不留 Audit）；object_type="interface"、object_id=Interface UUID；快照白名单 {resource_id,name,interface_type,mac_address,speed_mbps,mtu,parent_interface_id,enabled,description,metadata}；UPDATE 记 before/after；不记敏感内容。Activity 按 (object_type,object_id) 过滤；完整跨对象审计归 F015/F016。

## 9. 业务边界
- F007 交付 Interface 独立对象与 /api/v1/interfaces 7 端点；不落 IP/CIDR/VLAN ID/所属 Network/网卡分类（§4/§10/§13）。
- **跨 Feature**：DELETE /api/v1/resources/{id} 随 F007 收窄——存在未删 Interface 时→409 reference_exists，references 含 {object_type:"interface",object_id,label}；IP 绑定/解绑/释放与 interface←IPAddress 引用集归 F010；Interfaces 聚合展示归 F013；导入字段口径复用归 F014；完整 Audit 查询归 F015。
- 不做 MAC 全局唯一、自动发现、实时速率/流量/状态采集；不据接口名推断类型；不建完整 Bond/Bridge/VLAN 拓扑。未定义路径/方法 404/405；id 非 UUID 404。不引入 pg_trgm/GIN。
