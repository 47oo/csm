## 1. 通用约定

- Base path /api/v1（§25），挂载同一 api_v1_router；路径 /api/v1/networks。
- 认证：csm_session HttpOnly Cookie（复用 F002 DR-08）；未认证先于权限返回 401。
- 时间：ISO-8601 UTC（D01 §2）。
- 操作者：服务端从 request.state.operator 取，写 Audit 快照（§22）；请求体不接受操作者字段。
- CSRF：不安全方法沿用 F002 §2.1；GET/HEAD 不校验。
- Network 为独立可寻址对象（自身 UUID/version/软删/恢复/Activity，DR-89/DR-97），不并入 F003 Cluster 嵌套；子对象 IPPool/IPAddress（F009/F010）经 network_id 关联。

### 1.1 统一错误信封（复用 F002 §1.1）
`{ "error": { "code": "STRING_CODE", "message": "human readable", "details": {} } }`

### 1.2 错误码与 HTTP 映射（复用 F002 集 + F003 CONFLICT；F008 仅新增 reason）

| HTTP | code | 触发 | details |
| --- | --- | --- | --- |
| 401 | AUTH_REQUIRED | 无有效会话 | {} |
| 403 | FORBIDDEN | 缺权限 / CSRF | {"reason":"permission"\|"csrf"} |
| 404 | NOT_FOUND | 不存在；或已软删且无 VIEW_DELETED；或未定义路径 | {} |
| 409 | VERSION_CONFLICT | 乐观锁过期 | {"current_version": int} |
| 409 | CONFLICT | 唯一/重叠/引用/恢复冲突 | 见下表 |
| 422 | VALIDATION_ERROR | 请求体/查询参数校验失败 | {"fields":[{"field":str,"message":str}]} |
| 500 | INTERNAL_ERROR | 未预期错误 | {} |

CONFLICT details.reason 枚举（复用 F003；F008 新增 range_overlap，不新增 code）：

| reason | 场景 | 附加字段 |
| --- | --- | --- |
| unique_conflict | 同 Cluster 未删 name（归一化键）冲突 | field:"name" |
| range_overlap（新） | 同 Cluster 未删 CIDR 重叠（含完全相同；创建/PATCH/恢复重检） | field:"cidr"；conflicts:[{object_type:"network",object_id,label}] |
| reference_exists | 删除/改 cidr/改 cluster 被未删 Pool/IP 引用 | references:[{object_type:"ip_pool"\|"ip_address",object_id,label}] |
| not_deleted | 对未软删对象 restore | {} |
| dependency_deleted | 恢复重检：所属 Cluster 仍软删/缺失 | conflicts:[{object_type:"cluster",object_id}] |

错误码注册表以 docs/api/F002.md §1.2 为共享权威；range_overlap 为 CONFLICT 下新增 reason（注册至 F002 §1.2 交叉引用），无新 error code。

### 1.3 权限（§23，复用 F002 §3）
列表/详情=READ；创建/更新=WRITE；删除=DELETE_OBJECT；查看已删除（deleted=include|only、详情 deleted=true）=VIEW_DELETED；恢复=RESTORE；Activity=VIEW_ACTIVITY（全角色）。服务端执行；前端隐藏不替代；未认证先于权限→401。

## 2. 字段契约与归一化

### 2.1 Network name（§4.1/§11，D01 §5.7，DR-90）
服务端 trim 首尾空白 → trim 后非空 → 禁控制字符（Unicode Cc/Cf，应用层；DB 为 ASCII backstop）→ 长度（Unicode code point）**1–255**。允许中文及其它 Unicode；**允许内部普通空格且不自动合并**；保留展示大小写。唯一：同 Cluster 未软删部分唯一 (cluster_id,name_key) WHERE deleted_at IS NULL；name_key=ASCII_lower(btrim(name))（仅 ASCII A-Z→a-z，非 ASCII 原样；应用禁 str.lower()，DB 禁 lower()，locale 无关）；软删后可复用；恢复重检冲突不覆盖。跨 Cluster 同名允许。

### 2.2 其它字段
- cluster：创建必填；接受 Cluster UUID 或 code（code 经 code_key 大小写不敏感精确解析），落库 UUID；引用须存在、未软删，否则 422 field="cluster"；有未删除 Pool/IP 引用时不可改（I-4）。
- cidr：创建必填；合法 IPv4 CIDR（PG 原生 cidr）；host 位接受并归一化为网络地址（'10.0.0.5/24'→'10.0.0.0/24'）；非 IPv4/非法/缺掩码→422 field="cidr"；同 Cluster 未删不重叠（INACTIVE 参与）；有未删除 Pool/IP 引用时不可改（I-4）。
- gateway：可选 nullable IPv4；填写须①属该 CIDR 基础可用地址（/0–/30 排网络/广播；/31 两址可用；/32 必空）②非 §11.1 禁用范围（0.0.0.0/8、127.0.0.0/8、169.254.0.0/16、224.0.0.0/4、240.0.0.0/4）；否则 422 field="gateway"；从可分配集合排除供 F009/F010/F013 共用；「已占用 IP 设为 gateway」冲突检测归 F009/F010（I-5）。
- status：可选默认 ACTIVE；∈{ACTIVE,INACTIVE}；显式 null/非法→422。
- auto_allocate：可选默认 false；boolean；显式 null→422；仅控自动分配，不绕过状态与地址约束。
- description：可选 nullable 文本。
- metadata：可选默认 {}；必须 JSON object；整值替换；显式 null/非 object→422；Network 自有（I-6）。
- version：int≥1；创建默认 1；PATCH/DELETE/restore 必填。

### 2.3 长度/数值口径（镜像 D01 §5.7 与 DB）
name 1–255；cidr IPv4；gateway IPv4；status 16；metadata JSON object。错误 fields[].field 用点路径：name、cluster、cidr、gateway、status、auto_allocate、metadata。

### 2.4 省略语义（D01 §4）
创建省略非必填→默认/null；PATCH 字段省略=保持不重置（exclude_unset）；显式 null 仅清空 nullable（gateway/description）；必填/非 nullable 显式 null（name/cidr/status/auto_allocate/metadata）→422；不可变/只读字段出现在请求体→422；未知字段→422。

## 3. Network 响应对象

| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| id | string(UUID) | 否 | 稳定 ID |
| cluster | object{id,code,name} | 否 | 所属 Cluster 嵌套展开 |
| name | string | 否 | trim 后（§2.1） |
| cidr | string | 否 | 归一化网络地址（PG cidr） |
| gateway | string\|null | 是 | 未设置 null |
| status | enum | 否 | ACTIVE\|INACTIVE，默认 ACTIVE |
| auto_allocate | bool | 否 | 默认 false |
| description | string\|null | 是 | 未设置 null |
| metadata | object | 否 | 默认 {}；整值替换；Network 自有 |
| version | int≥1 | 否 | 乐观锁 |
| created_at/updated_at | ISO-8601 UTC | 否 | |
| deleted_at | ISO-8601 UTC | 是 | 未删 null |

name_key 不暴露。列表响应 {items,page,page_size,total}。

## 4. 分页/排序/过滤
分页 page≥1 默认 1；page_size 1–100 默认 20；越界/非整数→422。排序 sort∈{name,cidr,status,created_at,updated_at} 默认 created_at；order∈{asc,desc} 默认 desc；非法→422；附 id 升序稳定；sort=name 按 name_key。过滤（AND）：cluster_id=UUID（非 UUID→422；不存在→空结果）；status∈{ACTIVE,INACTIVE}（非法→422）；auto_allocate=bool（非法→422）；q=对 name 的**大小写不敏感子串**（空/纯空白视为未提供，不用 pg_trgm）；deleted∈{exclude,include,only} 默认 exclude。未列出参数忽略；条件仅作用于可见集合。

## 5. 软删可见性
列表 deleted∈{exclude,include,only} 默认 exclude；非法 422；include/only 需 VIEW_DELETED 否则 403 FORBIDDEN{reason:"permission"}。详情默认不可见软删对象；?deleted=true 需 VIEW_DELETED 否则 403；默认视图下软删返回 404（不泄露存在性）。Activity 对已删同理。

## 6. Endpoints

### 6.1 GET /api/v1/networks — READ（deleted=include|only 另需 VIEW_DELETED）
Query cluster_id/status/auto_allocate/q/deleted/page/page_size/sort/order（§4）。成功 200 列表。错误 401/403/422/500。

### 6.2 POST /api/v1/networks — WRITE
Request：cluster(必填 UUID 或 code)、name(必填 §2.1)、cidr(必填 §2.2)、gateway(可选 null)、status(可选默认 ACTIVE)、auto_allocate(可选默认 false)、description(可选 null)、metadata(可选默认 {})；未列/只读字段→422。成功 201 {"network":Network}；同事务写 CREATE Audit。
错误：401/403 / 409 CONFLICT{unique_conflict,field:"name"} / 409 CONFLICT{range_overlap,field:"cidr",conflicts} / 422（body 非法、cluster 缺失/不存在/软删 field="cluster"、cidr 非法 field="cidr"、gateway 越界/禁用 field="gateway"）/ 500。
**校验顺序**：401→403→body(422)→cluster(422)→name 唯一(409)→cidr 格式/gateway 边界(422)→cidr 重叠(409 range_overlap)→写+Audit→201。

### 6.3 GET /api/v1/networks/{id} — READ
id=UUID（非 UUID→404）；Query deleted(bool 默认 false；true 需 VIEW_DELETED 否则 403)。成功 200 {"network":Network}。错误 401/403/404/500。

### 6.4 PATCH /api/v1/networks/{id} — WRITE
Body（exclude_unset，省略=保持；含 version 必填 int≥1）：name(可选，改后重检唯一)、cidr(可选，改后重检重叠与引用)、gateway(可选；显式 null 清空；改 cidr 时重检)、cluster(可选 UUID 或 code，改后重检引用与目标 Cluster)、status(可选；显式 null→422)、auto_allocate(可选；显式 null→422)、description(可选；显式 null 清空)、metadata(可选；整值替换；显式 null/非 object→422)；含 id/name_key/只读字段→422。
成功 200 {"network":Network}；version+1；写 UPDATE Audit（before/after）；改 cidr/cluster 事务内对 networks 行 SELECT ... FOR UPDATE 串行化。
错误：401/403/404 / 409 VERSION_CONFLICT / 409 CONFLICT{unique_conflict,field:"name"} / 409 CONFLICT{range_overlap,field:"cidr",conflicts} / 409 CONFLICT{reference_exists,references} / 422（body/cluster/cidr/gateway）。
**校验顺序**：401→403→body(422)→可见性(404)→version(409)→name 唯一(409)→cidr/gateway(422)→依赖引用(409 reference_exists)→cidr 重叠(409 range_overlap)→写+Audit→200。

### 6.5 DELETE /api/v1/networks/{id} — DELETE_OBJECT
Query version(必填 int≥1)。软删（置 deleted_at、version+1、updated_at）；不级联；引用检查：存在未删 IPPool（object_type:"ip_pool"）或 IPAddress（object_type:"ip_address"）引用（F008 前台为空集，F009/F010 注册后生效）→409 CONFLICT{reference_exists,references:[{object_type,object_id,label}]}。成功 204；写 DELETE Audit。
错误 401/403/404/409 VERSION_CONFLICT/409 CONFLICT{reference_exists}/422/500。
**顺序**：401→403→对象(404)→version 校验(422)→版本(409)→引用(409)→软删。

### 6.6 POST /api/v1/networks/{id}/restore — RESTORE
Query version(必填 int≥1)。置 deleted_at=null、version+1、updated_at；仅恢复自身不级联；重检（§21）：同 Cluster name 唯一、所属 Cluster 未软删、CIDR 不重叠、引用有效性。失败不覆盖新对象。成功 200；写 RESTORE Audit。
错误 401/403 / 404 / 409 CONFLICT{not_deleted} / 409 VERSION_CONFLICT / 409 CONFLICT{unique_conflict,field:"name"} / 409 CONFLICT{dependency_deleted,conflicts:[{object_type:"cluster",object_id}]} / 409 CONFLICT{range_overlap,field:"cidr",conflicts} / 422 / 500。
**顺序**：401→403→查找(含软删,404)→未删则 409 not_deleted→版本(409)→name 唯一(409)→cluster 依赖(409)→cidr 重叠(409)→恢复。**name 复用优先于依赖失效与重叠。**

### 6.7 GET /api/v1/networks/{id}/activity — VIEW_ACTIVITY（全角色）
Query deleted(bool 默认 false；已删需 true+VIEW_DELETED)、page/page_size。返回 (object_type="network",object_id=id) 审计 created_at 升序、同刻 id 升序。成功 200 {items:[ActivityItem],page,page_size,total}；ActivityItem{id,action(CREATE|UPDATE|DELETE|RESTORE),operator_user_id(UUID|null),operator_username,string,before_data(object|null),after_data(object|null),created_at}。只读无修改/删除入口（§22）。错误 401/403/404/422/500。

## 7. 并发与错误语义小结
乐观锁条件 UPDATE WHERE id AND version=:expected SET version=version+1；rowcount=0→对象仍可见则 409 VERSION_CONFLICT{current_version}，不可见/不存在则 404；无静默重试。唯一/重叠：创建/改名/恢复冲突 409 CONFLICT{unique_conflict|range_overlap}；DB uq_networks_cluster_id_name_key 部分唯一与 excl_networks_cluster_id_cidr 排他约束并发兜底。改 cidr/cluster 与删除共用引用集，事务内 networks 行 SELECT ... FOR UPDATE 串行化（F009/F010 创建子对象须取同 Network 行锁，跨 Feature 协议，I-4）。422=格式/字段/形状非法；409=语义冲突。

## 8. Audit 一致性（§22/D02）
四类 action 各写一行 audit_logs；同事务（业务 Service 内同 Session 一并 commit，异常一起 rollback，回滚不留 Audit）；object_type="network"、object_id=Network UUID；快照白名单 {cluster_id,name,cidr,gateway,status,auto_allocate,description,metadata}；UPDATE 记 before/after；不记敏感内容。Activity 按 (object_type,object_id) 过滤；完整跨对象审计归 F015/F016。

## 9. 业务边界
F008 交付 Network 独立对象与 /api/v1/networks 7 端点，及可被 F009/F010/F013 复用的 CIDR/网关边界语义（基础可用地址 − gateway − RESERVED − 禁用清单）。不实现 IPPool 起止/allocation_mode/池重叠（F009）、IP 分配/解绑/释放/IP 唯一性/地址边界执行与容量数值（F010/F013）、「已占用 IP 设为 gateway」冲突检测（I-5）、CSV/Excel 导入（F014）、全局搜索/Dashboard/列表聚合（F013）、完整 Audit 查询（F015）；不做 IPv6/DHCP/路由/防火墙/VLAN 划分/网段发现/实时监控。Network 不落 VLAN ID、网络分类、Pool/IP 列表。未定义路径/方法 404/405；id 非 UUID 404；不引入 pg_trgm/GIN。
