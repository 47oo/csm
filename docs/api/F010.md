## 1. 通用约定
- Base path /api/v1（§25），挂载同一 api_v1_router；路径 /api/v1/ip-addresses。
- 认证：csm_session HttpOnly Cookie（复用 F002 DR-08）；未认证先于权限返回 401。
- 时间：ISO-8601 UTC（D01 §2）。
- 操作者：服务端从 request.state.operator 取，写 Audit 快照（§22）；请求体不接受操作者字段。
- CSRF：不安全方法沿用 F002 §2.1；GET/HEAD 不校验。
- IPAddress 为独立可寻址对象（自身 UUID/version/软删/恢复/Activity）；归属 Network 经 network_id 关联；Network/Interface/IPPool 本体不并入。

### 1.1 统一错误信封（复用 F002 §1.1）
`{ "error": { "code": "STRING_CODE", "message": "human readable", "details": {} } }`

### 1.2 错误码与 HTTP 映射（复用 F002 集 + F003/F008/F009 CONFLICT；F010 新增 reason）

| HTTP | code | 触发 | details |
| --- | --- | --- | --- |
| 401 | AUTH_REQUIRED | 无有效会话 | {} |
| 403 | FORBIDDEN | 缺权限 / CSRF | {"reason":"permission"\|"csrf"} |
| 404 | NOT_FOUND | 不存在；或已软删且无 VIEW_DELETED；或未定义路径 | {} |
| 409 | VERSION_CONFLICT | 乐观锁过期 | {"current_version": int} |
| 409 | CONFLICT | 唯一/引用/分配条件/耗尽/恢复冲突 | 见下表 |
| 422 | VALIDATION_ERROR | 请求体/查询参数/地址校验失败 | {"fields":[{"field":str,"message":str}]} |
| 500 | INTERNAL_ERROR | 未预期错误 | {} |

CONFLICT details.reason 枚举（F010 新增 2，复用 F003/F008/F009）：

| reason | 场景 | 附加字段 |
| --- | --- | --- |
| unique_conflict（复用 F003） | 同 Cluster 未删地址冲突（创建/恢复重检） | field:"address" |
| allocation_not_allowed（新，DR-125/DR-136） | 新增分配条件不满足：Network INACTIVE / auto_allocate 关闭 / 指定池非 AUTO | condition:"network_inactive"\|"auto_allocate_disabled"\|"pool_not_auto" |
| no_available_address（新，DR-125） | 自动分配在指定池内无可用地址（不切换其它池） | {network_id, ip_pool_id} |
| reference_exists（复用 F003/F007/F008） | 解绑/转移/释放被未删 Endpoint 引用；删除/改 Network 或 Interface 被未删 IP 引用 | references:[{object_type:"endpoint"\|"ip_address",object_id,label}] |
| not_deleted（复用 F003） | 对未软删对象 restore | {} |
| dependency_deleted（复用 F003） | 恢复重检：所属 Network/Interface 仍软删或缺失、或 Network cluster 变更致不一致 | conflicts:[{object_type:"network"\|"interface",object_id}] |
| address_in_use（复用 F009，经真实占用提供者） | Network PATCH 设已占用 gateway（含未绑定） | field:"gateway"；conflict_count；conflicts；conflicts_truncated |

- 错误码注册表以 docs/api/F002.md §1.2 为共享权威；F010 新增 `allocation_not_allowed`、`no_available_address` 并登记 F002 **§1.2.1**；复用 `unique_conflict`/`reference_exists`/`not_deleted`/`dependency_deleted`/`address_in_use`，无新 error code。
- **CONFLICT_PREVIEW_LIMIT** 沿用 F009（默认 100），作用于 `address_in_use.conflicts`。
- `address_in_use` 由 F010 注册的真实 `IpAddressOccupancyProvider` 使 F008 gateway 路径可达（F009-CON-01；详见 F008 errata）。

### 1.3 权限（§23，复用 F002 §3）
列表/详情/容量=READ；手动分配/自动分配（创建）=WRITE；绑定/解绑/转移（PATCH）=WRITE；释放（DELETE）=**RELEASE_IP**；查看已删（deleted=include|only、详情 deleted=true）=VIEW_DELETED；恢复=RESTORE；Activity=VIEW_ACTIVITY（全角色）。服务端执行；前端隐藏不替代；未认证先于权限→401。EDITOR 解绑不隐式释放。

## 2. 字段契约与归一化

### 2.1 IPAddress address（§11.1/§13/§14，D01 §5.9，DR-120）
单个 IPv4 **主机地址**（非 CIDR/掩码；PG `inet`，family=4、masklen=32）。输入须为裸点分十进制 IPv4；含前缀/掩码（如 `10.0.0.1/24`）、CIDR 形式、IPv6、非法串 → 422 field="address"（不静默归一化）。响应为点分十进制 IPv4（不含 `/32`）。
创建必填；须属所属 Network 的 CIDR（应用主校验；DB 触发器 `trg_ip_addresses_cidr_contains` backstop）；不得为网络地址/广播地址（§11.1：/0–/30 排除网络/广播；/31 两址可用；/32 唯一可用）；不得在禁用 5 段（0.0.0.0/8、127.0.0.0/8、169.254.0.0/16、224.0.0.0/4、240.0.0.0/4；应用 422 + DB `ck_ip_addresses_address_not_disabled` backstop）；不得为 gateway、不得在 RESERVED 池范围（跨表应用主校验）。创建后不可改（PATCH 含 address→422）。唯一：同 Cluster 未软删 `(cluster_id,address)` 部分唯一 `uq_ip_addresses_cluster_id_address`；不同 Cluster 可重复；软删后可重用；恢复重检不覆盖。

### 2.2 其它字段
- network：创建必填 UUID；引用须存在、未软删，否则 422 field="network"；创建后不可改（PATCH 出现 network/network_id→422，DR-120）。仅新建分配要求 Network ACTIVE（非 ACTIVE→409 allocation_not_allowed{condition:"network_inactive"}）。
- interface：可选 nullable UUID；非空须引用存在、未软删 Interface 且 `Interface.Resource.cluster == IPAddress.cluster`，否则 422 field="interface"（应用主校验 + DB 触发器 `trg_ip_addresses_interface_cluster` backstop）；可 PATCH 变更（绑定/解绑/转移）；显式 null=解绑（IP 继续占用）。POST 创建不接受 interface（出现→422，分配与绑定分离，DR-137）。
- ip_pool（分配来源）：只读；自动=指定 AUTO 池、手动=地址所属未删池或 null；请求体出现→422（服务端推导，DR-122）；创建后不可改。
- cluster_id：冗余内部列（创建时取自锁定 Network 的 cluster），不暴露；请求体出现 cluster_id→422。
- description：可选 nullable 文本；无长度上限。
- version：int≥1；创建默认 1；PATCH/DELETE/restore 必填。
- metadata：不接受、不暴露；请求含 metadata→422（未知字段）；响应不含（I-3/DR-123）。

### 2.3 长度/数值口径（镜像 D01 §5.9 与 DB）
address IPv4 主机地址；错误 fields[].field 用点路径：network、address、interface、description。

### 2.4 省略语义（D01 §4）
创建省略非必填→默认/null；PATCH 字段省略=保持不重置（exclude_unset）；显式 null 仅清空 nullable（interface/description）；必填/非 nullable 显式 null（network/address）→422；不可变/只读字段（network、network_id、address、cluster_id、ip_pool、ip_pool_id、id）出现在请求体→422；未知字段→422。

## 4. 分页/排序/过滤
- 分页：page≥1 默认 1；page_size 1–100 默认 20；越界/非整数→422。
- 排序：sort∈{address,created_at,updated_at} 默认 created_at；order∈{asc,desc} 默认 desc；非法→422；附 id 升序稳定；sort=address 按数值地址升序。
- 过滤（AND）：
  - network_id=UUID（非 UUID→422；不存在→空结果）
  - cluster_id=UUID（非 UUID→422；不存在→空结果）
  - interface_id=UUID（非 UUID→422；不存在→空结果）
  - ip_pool_id=UUID（非 UUID→422；不存在→空结果）
  - address=IPv4 主机地址（非法→422；精确匹配）
  - bound=bool（true=interface 非空；false=未绑定）
  - q=对 address 的大小写不敏感子串（空/纯空白视为未提供，不用 pg_trgm）
  - deleted∈{exclude,include,only} 默认 exclude
- 未列出参数忽略；条件仅作用于可见集合。

## 5. 软删可见性
列表 deleted∈{exclude,include,only} 默认 exclude；非法 422；include/only 需 VIEW_DELETED 否则 403 FORBIDDEN{reason:"permission"}。详情默认不可见软删对象；?deleted=true 需 VIEW_DELETED 否则 403；默认视图下软删返回 404（不泄露存在性）。Activity 对已删同理。

## 6. Endpoints

### 6.1 GET /api/v1/ip-addresses — READ（deleted=include|only 另需 VIEW_DELETED）
Query network_id/cluster_id/interface_id/ip_pool_id/address/bound/q/deleted/page/page_size/sort/order（§4）。成功 200 列表。错误 401/403/422/500。

### 6.2 POST /api/v1/ip-addresses — WRITE（手动分配=创建）
Request：network(必填 UUID)、address(必填 §2.1)、description(可选 null)；未列/只读字段（含 interface、ip_pool、metadata、cluster_id）→422。成功 201 {"ip_address":IPAddress}（interface=null；ip_pool 服务端推导）；同事务写 CREATE Audit。
错误：401/403 / 409 CONFLICT{unique_conflict,field:"address"} / 409 CONFLICT{allocation_not_allowed,condition:"network_inactive"} / 422（body、network 缺失/不存在/软删 field="network"、address 非法/带掩码/越界/网络广播/禁用/gateway/RESERVED field="address"）/ 500。
**校验顺序**：401→403→body(422，含 interface/ip_pool/metadata/cluster_id 只读)→network 存在/未软删(422)→取 `_lock_network`（networks 行 FOR UPDATE）→Network ACTIVE(409 allocation_not_allowed{network_inactive})→address 格式/主机/属 CIDR/非网络广播/非禁用/非 gateway/非 RESERVED(422)→同 Cluster 唯一(409 unique_conflict)→推导 ip_pool→写+Audit→201。

### 6.3 POST /api/v1/ip-addresses/auto-allocate — WRITE（自动分配=创建）
Request：network(必填 UUID)、ip_pool(必填 UUID)、description(可选 null)；未列/只读字段→422。
条件：Network 存在未软删且 ACTIVE；auto_allocate=true；ip_pool 存在未软删、属该 Network、`allocation_mode=AUTO`。否则 409 allocation_not_allowed（condition:"network_inactive"|"auto_allocate_disabled"|"pool_not_auto"），**不降级为手动**。
算法：事务内取 `_lock_network`；在指定池范围 ∩ Network 可分配集合（§11.1）内按地址升序选第一个未被未删 IP 占用的地址；池耗尽→409 CONFLICT{no_available_address,network_id,ip_pool_id}，不切换。成功 201 {"ip_address":IPAddress}（interface=null；ip_pool_id=指定池）；CREATE Audit。
**校验顺序**：401→403→body(422)→network(422)→取 `_lock_network`→Network ACTIVE(409)→ip_pool 存在/未软删/属本 Network(422)→auto_allocate(409 auto_allocate_disabled)→allocation_mode=AUTO(409 pool_not_auto)→升序选可用→无→409 no_available_address→写+Audit→201。

### 6.4 GET /api/v1/ip-addresses/{id} — READ
id=UUID（非 UUID→404）；Query deleted(bool 默认 false；true 需 VIEW_DELETED 否则 403)。成功 200 {"ip_address":IPAddress}。错误 401/403/404/500。

### 6.5 PATCH /api/v1/ip-addresses/{id} — WRITE（绑定/解绑/转移/字段）
Body（exclude_unset，省略=保持；含 version 必填 int≥1）：interface(可选，nullable UUID；非空绑定/转移，null 解绑；变更后重检存在/未软删/同 Cluster)、description(可选；显式 null 清空)；含 network/address/cluster_id/ip_pool/id/只读字段→422。
成功 200 {"ip_address":IPAddress}；version+1；写 UPDATE Audit（before/after）。interface 变更前调用 IP 引用检查器（Endpoint 挂钩，DR-139）；命中→409 CONFLICT{reference_exists,references}。
错误：401/403/404 / 409 VERSION_CONFLICT / 409 CONFLICT{reference_exists} / 422（body/interface 跨 Cluster、不存在、软删）/ 500。
**校验顺序**：401→403→body(422)→可见性(404)→version(409)→interface 校验(422)→（仅 interface 变更时）引用检查(409 reference_exists)→写+Audit→200。
说明：绑定/解绑/转移为关系编辑，不受 Network INACTIVE 限制（DR-136）；网络/地址不可改（DR-120）。

### 6.6 DELETE /api/v1/ip-addresses/{id} — RELEASE_IP（ADMIN 释放）
Query version(必填 int≥1)。软删（置 deleted_at、version+1、updated_at）；不级联；释放前调用 IP 引用检查器（Endpoint）→命中 409 reference_exists；不自动解绑其它对象。成功 204；写 DELETE Audit。
错误 401/403/404/409 VERSION_CONFLICT/409 CONFLICT{reference_exists}/422/500。
**顺序**：401→403→对象(404)→version 校验(422)→版本(409)→引用(409)→软删。

### 6.7 POST /api/v1/ip-addresses/{id}/restore — RESTORE（ADMIN）
Query version(必填 int≥1)。置 deleted_at=null、version+1、updated_at；仅恢复自身不级联；重检（§21/DR-128）：同 Cluster 地址唯一、所属 Network 未软删、地址仍属 Network CIDR、cluster 一致性、绑定 Interface（若 interface_id 非空）仍存在且未软删且同 Cluster；失败不覆盖新对象。成功 200；写 RESTORE Audit。
错误 401/403 / 404 / 409 CONFLICT{not_deleted} / 409 VERSION_CONFLICT / 409 CONFLICT{unique_conflict,field:"address"} / 409 CONFLICT{dependency_deleted,conflicts:[{object_type:"network"|"interface",object_id}]} / 422 VALIDATION_ERROR{field:"address"}（Network cidr 变更后软删 IP 越界）/ 500。
**优先级**：401→403→查找(含软删,404)→未删则 409 not_deleted→版本(409)→地址唯一(409 unique_conflict)→Network/Interface 依赖(409 dependency_deleted)→CIDR 包含重检(422)→恢复。
说明：地址唯一优先于依赖失效与越界；恢复不要求 Network ACTIVE（DR-136）；恢复不自动恢复 Interface/Endpoint 关系。

### 6.8 GET /api/v1/ip-addresses/{id}/activity — VIEW_ACTIVITY（全角色）
Query deleted(bool 默认 false；已删需 true+VIEW_DELETED)、page/page_size。返回 (object_type="ip_address",object_id=id) 审计 created_at 升序、同刻 id 升序。成功 200 {items:[ActivityItem],page,page_size,total}；ActivityItem{id,action(CREATE|UPDATE|DELETE|RESTORE),operator_user_id(UUID|null),operator_username(string),before_data(object|null),after_data(object|null),created_at}。只读无修改/删除入口（§22）。错误 401/403/404/422/500。

### 6.9 GET /api/v1/networks/{id}/capacity — READ（§20 容量数据，显示归 F013）
id=Network UUID（非 UUID→404）。成功 200：
```json
{
  "network_capacity": {
    "network": {"id":"…","name":"…","cidr":"10.10.0.0/16","status":"ACTIVE","auto_allocate":true},
    "allocatable_total": 65534,
    "occupied": 120,
    "remaining": 65414
  },
  "auto_pools": [
    {"ip_pool":{"id":"…","name":"…","start_address":"10.10.1.50","end_address":"10.10.1.200"},
     "allocatable_total": 151, "occupied": 12, "remaining": 139}
  ]
}
```
口径（§20/DR-130）：`allocatable_total`=基础可用地址（§11.1 按前缀）−gateway−RESERVED 池范围−禁用地址（去重）；`occupied`=该 Network 下未删 IP 数（含未绑定、含池外手动）；`remaining=allocatable_total−occupied`；AUTO 池 `allocatable_total=|池范围∩Network 可分配集合|`、`occupied=当前位于该交集的未删 IP 数`（按当前地址、不按来源）、`remaining=差`。停用不清零；未删 Network 才返回（软删→404）。错误 401/403/404/500。
**`remaining` 负值口径（定稿裁定）**：按公式直接相减，**不设下限 0、不截断**；存量 IP 落入现已保留（RESERVED/新增 gateway/禁用）范围时 `remaining` 可为负，原样返回，供 F013 呈现。拒绝静默修正或隐藏。

## 7. 并发与错误语义小结
- 乐观锁：条件 UPDATE WHERE id AND version=:expected SET version=version+1；rowcount=0→对象仍可见则 409 VERSION_CONFLICT{current_version}，不可见/不存在则 404；无静默重试。
- 同 Cluster 唯一：创建/恢复冲突 409 CONFLICT{unique_conflict,field:"address"}；DB `uq_ip_addresses_cluster_id_address`（部分唯一 WHERE deleted_at IS NULL）并发兜底。
- 分配条件/耗尽：409 allocation_not_allowed / no_available_address。
- 锁域（DR-126/DB-D125）：手动/自动分配与恢复事务内取 `_lock_network`（networks 行 FOR UPDATE）；与 F009/F008 变更共用，保证 §12.1/§11.1 与 T35；三个触发 backstop 对 networks 行 `FOR KEY SHARE` 串行。
- 引用：解绑/转移/释放前调用 IP 引用检查器（F010 空集，F012 注册 Endpoint）；删除/改 Network/Interface 时其引用检查器含未删 IP。
- 占用：F010 注册真实 `IpAddressOccupancyProvider`（F009 注册表）；F009/F008 的 `address_in_use` 409 由此可达（F009-CON-01）。
- 422=格式/字段/形状/地址不可分配；409=语义冲突；404=不可见/不存在；403=权限。

## 8. Audit 一致性（§22/D02）
四类 action 各写一行 audit_logs；同事务；object_type="ip_address"、object_id=IPAddress UUID；快照白名单 {network_id,cluster_id,address,interface_id,ip_pool_id,description}；UPDATE 记 before/after（含 interface 绑定/解绑/转移）；不记敏感内容。Activity 按 (object_type,object_id) 过滤；完整跨对象审计归 F015/F016。

## 9. 业务边界
F010 交付 IPAddress 独立对象与 /api/v1/ip-addresses 8 端点 + 容量数据端点，及可被 F009/F008/F013 复用的同 Cluster 唯一、可分配集合、占用提供者与容量口径。不实现 Endpoint/Service（F011/F012，仅预留 `Endpoint←IPAddress` 引用检查注册点）、Dashboard 显示与全局搜索（F013，仅提供容量数据）、CSV/Excel 导入（F014）、完整 Audit（F015）；不做 IPv6/DHCP/路由/防火墙/VLAN 划分/网段发现/实时监控；不由地址推断 Resource/Service/角色/网络分类；不自动创建 Endpoint/Service/DNS。IPAddress 不落 metadata/name/status/实时探测。未定义路径/方法 404/405；id 非 UUID 404。

**跨 Feature 契约**：
- 解绑/转移/释放被未删 Endpoint 引用时拒绝（§16/§21/T22）；F010 交付检查契约与 `register_ip_address_reference_checker` 挂钩（默认空集）；含 Endpoint 的端到端在 F012 集成。
- 存在未删 IP 时 Network/Interface 删除或改 cidr/cluster 被拒（§21/T23）；IPPool 来源例外（§12/T34）。
- 容量显示归 F013（本 Feature 提供 §20 数据端点/Provider）。
- F010 必须复用 `_lock_network` 并注册真实 `IpAddressOccupancyProvider`（跨 Feature 协议，F009 I-5/DR-109/DR-110）。
