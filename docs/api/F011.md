## 1. 通用约定
- Base path /api/v1（§25），挂载同一 api_v1_router；路径 /api/v1/services。
- 认证：csm_session HttpOnly Cookie（复用 F002 DR-08）；未认证先于权限返回 401。
- 时间：ISO-8601 UTC（D01 §2）。
- 操作者：服务端从 request.state.operator 取，写 Audit 快照（§22）；请求体不接受操作者字段。
- CSRF：不安全方法沿用 F002 §2.1；GET/HEAD 不校验。
- Service 为独立可寻址对象（自身 UUID/version/软删/恢复/Activity，DR-140/DR-149）；归属 Resource 经 resource_id 关联；Resource 本体不并入。

### 1.1 统一错误信封（复用 F002 §1.1）
`{ "error": { "code": "STRING_CODE", "message": "human readable", "details": {} } }`

### 1.2 错误码与 HTTP 映射（复用 F002 集 + F003/F004 CONFLICT；F011 不新增 code / reason）

| HTTP | code | 触发 | details |
| --- | --- | --- | --- |
| 401 | AUTH_REQUIRED | 无有效会话 | {} |
| 403 | FORBIDDEN | 缺权限 / CSRF | {"reason":"permission"\|"csrf"} |
| 404 | NOT_FOUND | 不存在；或已软删且无 VIEW_DELETED；或未定义路径 | {} |
| 409 | VERSION_CONFLICT | 乐观锁过期 | {"current_version": int} |
| 409 | CONFLICT | 名称/引用/恢复冲突 | 见下表 |
| 422 | VALIDATION_ERROR | 请求体/查询参数/reference 校验失败 | {"fields":[{"field":str,"message":str}]} |
| 500 | INTERNAL_ERROR | 未预期错误 | {} |

CONFLICT details.reason 枚举（复用 F003/F004，F011 不新增）：

| reason | 场景 | 附加字段 |
| --- | --- | --- |
| unique_conflict | 同 Resource 未删 name（归一化键）冲突（创建/PATCH 改名/恢复重检） | field:"name" |
| not_deleted | 对未软删对象 restore | {} |
| dependency_deleted | 恢复重检：所属 Resource 仍软删/缺失 | conflicts:[{object_type:"resource",object_id}] |
| reference_exists | 删除 Service 被未删 ServiceEndpoint 引用（F012 提供数据；F011 默认空集） | references:[{object_type:"service_endpoint",object_id,label}] |

- 错误码注册表以 docs/api/F002.md §1.2 为共享权威；F011 复用 `reference_exists`（F004 登记）与 `unique_conflict`/`not_deleted`/`dependency_deleted`（F003/F004），不新增 code 或 reason。

### 1.3 权限（§23，复用 F002 §3）
列表/详情=READ；创建/更新=WRITE；删除=DELETE_OBJECT；查看已删除（deleted=include|only、详情 deleted=true）=VIEW_DELETED；恢复=RESTORE；Activity=VIEW_ACTIVITY（全角色）。服务端执行；前端隐藏不替代；未认证先于权限→401。

## 2. 字段契约与归一化

### 2.1 Service name（§4.1/§15，D01 §5.10，DR-141）
服务端 trim 首尾空白 → trim 后非空 → 禁控制字符（Unicode Cc/Cf，应用层；DB 为 ASCII backstop）→ 长度（Unicode code point）1–255。允许中文及其它 Unicode；允许内部普通空格且不自动合并；保留展示大小写。唯一：同 Resource 未软删部分唯一 `(resource_id,name_key) WHERE deleted_at IS NULL`；`name_key=ASCII_lower(btrim(name))`（仅 ASCII A-Z→a-z，非 ASCII 原样；应用禁 `str.lower()`，DB 禁 `lower()`，locale 无关）；软删后可复用；恢复重检冲突不覆盖新对象。跨 Resource 同名允许。

### 2.2 其它字段
- resource：创建必填；Resource UUID；引用须存在、未软删，否则 422 field="resource"；**创建后不可改**（PATCH 出现 resource/resource_id→422，DR-144）。无 resource_type 限制。
- status：可选默认 UNKNOWN；∈{RUNNING,STOPPED,UNKNOWN}；显式 null/非法→422；人工维护、非探测、不由名称或外部监控推导/自动转换（§15/T21）。
- description：可选 nullable 文本；无长度上限。
- metadata：可选默认 {}；必须 JSON object；整值替换；显式 null／非 object→422；Service 自有（不并入 Resource 公共 metadata）。
- version：int≥1；创建默认 1；PATCH/DELETE/restore 必填。

### 2.3 长度/数值口径（镜像 D01 §5.10 与 DB）
name 1–255；status 16。错误 fields[].field 用点路径：resource、name、status、description、metadata。

### 2.4 省略语义（D01 §4）
创建省略非必填→默认/null；PATCH 字段省略=保持不重置（exclude_unset）；显式 null 仅清空 nullable（description）；必填/非 nullable 显式 null（resource/name/status/metadata）→422；不可变/只读字段（resource、resource_id、id、name_key）出现在请求体→422；未知字段→422。

## 3. Service 响应对象

| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| id | string(UUID) | 否 | 稳定 ID |
| resource | object{id,hostname} | 否 | 所属 Resource 嵌套展开 |
| name | string | 否 | trim 后（§2.1） |
| status | enum | 否 | RUNNING\|STOPPED\|UNKNOWN，默认 UNKNOWN |
| description | string\|null | 是 | 未设置 null |
| metadata | object | 否 | 默认 {}；整值替换 |
| version | int≥1 | 否 | 乐观锁 |
| created_at/updated_at | ISO-8601 UTC | 否 | |
| deleted_at | ISO-8601 UTC | 是 | 未删 null |

name_key 不暴露。列表响应 {items,page,page_size,total}。

## 4. 分页/排序/过滤
- 分页：page 整数 ≥1 默认 1；page_size 1–100 默认 20；越界/非整数→422。
- 排序：sort∈{name,status,created_at,updated_at} 默认 created_at；order∈{asc,desc} 默认 desc；非法→422；附 id 升序稳定；sort=name 按 name_key。
- 过滤（AND）：
  - resource_id=UUID（非 UUID→422；不存在→空结果）
  - status∈{RUNNING,STOPPED,UNKNOWN}（非法→422）
  - q=对 name 的大小写不敏感子串（trim 后空/纯空白视为未提供，不用 pg_trgm）
  - deleted∈{exclude,include,only} 默认 exclude
- 未列出参数忽略；条件仅作用于可见集合。不新增 cluster 过滤参数（DR-153）。

## 5. 软删可见性
列表 deleted∈{exclude,include,only} 默认 exclude；非法 422；include/only 需 VIEW_DELETED 否则 403 FORBIDDEN{reason:"permission"}。详情默认不可见软删对象；?deleted=true 需 VIEW_DELETED 否则 403；默认视图下软删返回 404（不泄露存在性）。Activity 对已删同理。

## 6. Endpoints

### 6.1 GET /api/v1/services — READ（deleted=include|only 另需 VIEW_DELETED）
Query resource_id/status/q/deleted/page/page_size/sort/order（§4）。成功 200 列表。错误 401/403/422/500。

### 6.2 POST /api/v1/services — WRITE
Request：resource(必填 UUID)、name(必填 §2.1)、status(可选默认 UNKNOWN)、description(可选 null)、metadata(可选默认 {})；未列/只读字段→422。成功 201 {"service":Service}；同事务写 CREATE Audit。
错误：401/403 / 409 CONFLICT{unique_conflict,field:"name"} / 422（body、resource 缺失/不存在/软删 field="resource"、name 非法、status 非法/null、metadata 非 object/null）/ 500。
**校验顺序**：401→403→body(422，含只读/未知字段)→resource(422，含存在/未软删)→name 归一化/校验(422)→name 唯一(409 unique_conflict)→写+Audit→201。
并发：名称唯一由部分唯一索引 `uq_services_resource_id_name_key` 原子兜底。

### 6.3 GET /api/v1/services/{id} — READ
id=UUID（非 UUID→404）；Query deleted(bool 默认 false；true 需 VIEW_DELETED 否则 403)。成功 200 {"service":Service}。错误 401/403/404/500。

### 6.4 PATCH /api/v1/services/{id} — WRITE
Body（exclude_unset，省略=保持；含 version 必填 int≥1）：name(可选，改后重检唯一)、status(可选；显式 null→422)、description(可选；显式 null 清空)、metadata(可选；整值替换；显式 null→422)；含 resource/resource_id/id/name_key/只读字段→422。
成功 200 {"service":Service}；version+1；写 UPDATE Audit（before/after）。
错误：401/403/404 / 409 VERSION_CONFLICT / 409 CONFLICT{unique_conflict,field:"name"} / 422。
**校验顺序**：401→403→body(422)→可见性(404)→version(409)→（若改名）name 归一化(422)→name 唯一(409)→写+Audit→200。

### 6.5 DELETE /api/v1/services/{id} — DELETE_OBJECT
Query version(必填 int≥1)。软删（置 deleted_at、version+1、updated_at）；不级联；**删除前调用 Service←ServiceEndpoint 引用检查**（F011 默认空集；F012 注册真实 provider）：有未删 Endpoint→409 `reference_exists{references:[{object_type:"service_endpoint",object_id,label}]}`。成功 204；写 DELETE Audit。
错误 401/403/404/409 VERSION_CONFLICT/409 CONFLICT{reference_exists}/422/500。
**顺序**：401→403→对象(404)→version 校验(422)→版本(409)→引用检查(409)→软删。

### 6.6 POST /api/v1/services/{id}/restore — RESTORE
Query version(必填 int≥1)。置 deleted_at=null、version+1、updated_at；仅恢复自身不级联、不自动恢复 Endpoint；重检（§21）：同 Resource name 唯一、所属 Resource 未软删/存在；失败不覆盖新对象。成功 200；写 RESTORE Audit。
错误 401/403 / 404 / 409 CONFLICT{not_deleted} / 409 VERSION_CONFLICT / 409 CONFLICT{unique_conflict,field:"name"} / 409 CONFLICT{dependency_deleted,conflicts:[{object_type:"resource",object_id}]} / 422 / 500。
**优先级（确定性）**：401→403→查找(含软删,404)→未删则 409 not_deleted→版本(409)→name 唯一(409 unique_conflict)→Resource 依赖(409 dependency_deleted)→恢复。

### 6.7 GET /api/v1/services/{id}/activity — VIEW_ACTIVITY（全角色）
Query deleted(bool 默认 false；已删需 true+VIEW_DELETED)、page/page_size。返回 (object_type="service",object_id=id) 审计 created_at 升序、同刻 id 升序。成功 200 {items:[ActivityItem],page,page_size,total}；ActivityItem{id,action(CREATE|UPDATE|DELETE|RESTORE),operator_user_id(UUID|null),operator_username(string),before_data(object|null),after_data(object|null),created_at}。只读无修改/删除入口（§22）。错误 401/403/404/422/500。

## 7. 并发与错误语义小结
- 乐观锁：条件 UPDATE WHERE id AND version=:expected SET version=version+1；rowcount=0→对象仍可见则 409 VERSION_CONFLICT{current_version}，不可见/不存在则 404；无静默重试。
- 名称唯一：创建/改名/恢复冲突 409 CONFLICT{unique_conflict,field:"name"}；DB `uq_services_resource_id_name_key`（部分唯一 WHERE deleted_at IS NULL）兜底并发。
- 删除引用：409 CONFLICT{reference_exists}（F011 默认空集 provider，F012 注册真实 Endpoint 检查器）。
- Resource←Service：未删 Service 阻塞 Resource 删除（F004 DELETE /resources 返回 409 reference_exists，references 含 object_type="service"）；由 F011 注册检查器实现。
- 422=格式/字段/形状非法；409=语义冲突。

## 8. Audit 一致性（§22/D02）
四类 action 各写一行 audit_logs；同事务；object_type="service"、object_id=Service UUID；快照白名单 {resource_id,name,status,description,metadata}；UPDATE 记 before/after；不记敏感内容。Activity 按 (object_type,object_id) 过滤；完整跨对象审计归 F015/F016。

## 9. 业务边界
F011 交付 Service 独立对象与 /api/v1/services 7 端点，及可被 F012/F013 复用的名称、状态与 Resource 归属语义；定义 Service←ServiceEndpoint 引用检查扩展点（默认空集）。不实现 ServiceEndpoint（F012）、Endpoint/IP 关系（F010/F012）、§19/§17/Dashboard（F013）、导入（F014）、完整 Audit（F015）；不做 Slurm 部署/状态同步/实时进程探测/自动状态转换。Service 不落 IP/端口/协议/监听地址/cluster 直字段/service_type/实时探测状态/自动部署标记；不由名称推断状态或行为。未定义路径/方法 404/405；id 非 UUID 404；不引入 pg_trgm/GIN。F012 须调用 `register_service_reference_checker` 注册真实 Endpoint 检查器（跨 Feature 协议，DR-146）。

## F027 范围语义（加法引用）

自 F027 起，本 Contract 的列表、详情、Activity 与写路径受 `docs/api/F027.md` 的范围附录约束：非 ADMIN 仅能访问已授权 Cluster 内对象；列表 `items`/`total` 与分页同谓词；未授权对象详情/写路径返回 404 `NOT_FOUND`；请求体显式引用未授权/不可选 Cluster 或父对象返回 422 `VALIDATION_ERROR`；范围校验先于唯一性/重叠/引用检查，不通过 409 泄露。本文件端点、字段、错误码、权限矩阵与版本冲突语义不变。
