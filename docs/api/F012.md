## 1. 通用约定
- Base path /api/v1（§25），挂载同一 api_v1_router；路径 /api/v1/service-endpoints。
- 认证：csm_session HttpOnly Cookie（复用 F002 DR-08）；未认证先于权限返回 401。
- 时间：ISO-8601 UTC（D01 §2）。
- 操作者：服务端从 request.state.operator 取，写 Audit 快照（§22）；请求体不接受操作者字段。
- CSRF：不安全方法沿用 F002 §2.1；GET/HEAD 不校验。
- ServiceEndpoint 为独立可寻址对象（自身 UUID/version/软删/恢复/Activity）；归属 Service 经 service_id、引用 IP 经 ip_address_id 关联；Service/IPAddress 本体不并入。

### 1.1 统一错误信封（复用 F002 §1.1）
`{ "error": { "code": "STRING_CODE", "message": "human readable", "details": {} } }`

### 1.2 错误码与 HTTP 映射（复用 F002 集 + F003/F010/F011 CONFLICT；F012 不新增 code / reason）

| HTTP | code | 触发 | details |
| --- | --- | --- | --- |
| 401 | AUTH_REQUIRED | 无有效会话 | {} |
| 403 | FORBIDDEN | 缺权限 / CSRF | {"reason":"permission"\|"csrf"} |
| 404 | NOT_FOUND | 不存在；或已软删且无 VIEW_DELETED；或未定义路径 | {} |
| 409 | VERSION_CONFLICT | 乐观锁过期 | {"current_version": int} |
| 409 | CONFLICT | 监听唯一/引用/恢复冲突 | 见下表 |
| 422 | VALIDATION_ERROR | 请求体/查询参数/归属校验失败 | {"fields":[{"field":str,"message":str}]} |
| 500 | INTERNAL_ERROR | 未预期错误 | {} |

CONFLICT details.reason 枚举（复用 F002/F003/F010/F011，F012 不新增）：

| reason | 场景 | 附加字段 |
| --- | --- | --- |
| unique_conflict | 同 IPAddress 未删 (protocol,port) 冲突（创建/PATCH 改 protocol·port/恢复重检） | field:"port"；ip_address_id；protocol；port |
| not_deleted | 对未软删对象 restore | {} |
| dependency_deleted | 恢复重检：所属 Service 或 ip_address 仍软删/缺失，或绑定 Interface 仍软删/缺失 | conflicts:[{object_type:"service"\|"ip_address"\|"interface",object_id}] |
| reference_exists | IP 解绑/转移/释放被未删 Endpoint 引用；删除 Service 被未删 Endpoint 引用 | references:[{object_type:"service_endpoint",object_id,label}] |

- 错误码注册表以 docs/api/F002.md §1.2 为共享权威；F012 复用 `unique_conflict`/`not_deleted`/`dependency_deleted`/`reference_exists`，不新增 code 或 reason。
- **`object_type` canonical 统一（I-4/DR-162）**：Endpoint 引用一律 `"service_endpoint"`。`docs/api/F010.md` §1.2 原用 `"endpoint"`，按 F010 errata-03 订正为 `"service_endpoint"`（不影响 F010 DONE 行为）。

### 1.3 权限（§23，复用 F002 §3）
列表/详情=READ；创建/更新=WRITE；删除=DELETE_OBJECT；查看已删（deleted=include|only、详情 deleted=true）=VIEW_DELETED；恢复=RESTORE；Activity=VIEW_ACTIVITY（全角色）。服务端执行；前端隐藏不替代；未认证先于权限→401。

## 2. 字段契约与归一化

### 2.1 service 与 ip_address（§16，D01 §5.11，DR-157/158）
- `service`：创建必填 UUID；须引用存在、未软删 Service，否则 422 field="service"；**创建后不可改**（PATCH 出现 service/service_id→422）。
- `ip_address`：创建必填 UUID；须引用存在、未软删 IPAddress，否则 422 field="ip_address"；且该 IP **已绑定 Interface**（`interface_id` 非空），该 Interface 存在、未软删，且 `interfaces.resource_id == services.resource_id`（同 Resource ⇒ 同 Cluster），否则 422 field="ip_address"；**创建后不可改**（PATCH 出现 ip_address/ip_address_id→422）。
- 不支持未绑定 IP、跨 Resource/跨 Cluster 共享 VIP（§16）。

### 2.2 protocol 与 port（§16，D01 §5.11，DR-160）
- `protocol`：创建必填；∈{TCP,UDP}；**仅接受大写规范值**，存储大写；显式 null/其它值（含 "tcp"）→422 field="protocol"。可 PATCH。
- `port`：创建必填；整数 1–65535（含端点）；0、65536、负数、非整数、显式 null→422 field="port"；边界 1、65535 接受。可 PATCH。

### 2.3 description 与其它
- `description`：可选 nullable 文本；无长度上限；显式 null 清空；省略保持。
- `version`：int≥1；创建默认 1；PATCH/DELETE/restore 必填。
- `metadata`：不接受、不暴露；请求含 metadata→422（未知字段）；响应不含（I-1/DR-156）。
- 无 name/status/listen_address 字段。

### 2.4 长度/数值口径（镜像 D01 §5.11 与 DB）
protocol 8；port 1–65535；错误 fields[].field 用点路径：service、ip_address、protocol、port、description。

### 2.5 省略语义（D01 §4）
创建省略非必填→默认/null；PATCH 字段省略=保持不重置（exclude_unset）；显式 null 仅清空 nullable（description）；必填/非 nullable（service/ip_address/protocol/port）显式 null→422；不可变/只读字段（service、service_id、ip_address、ip_address_id、id）出现在请求体→422；未知字段（含 metadata）→422。

## 3. ServiceEndpoint 响应对象

| 字段 | 类型 | nullable | 说明 |
| --- | --- | --- | --- |
| id | string(UUID) | 否 | 稳定 ID |
| service | object{id,name,resource{id,hostname}} | 否 | 所属 Service 嵌套展开 |
| ip_address | object{id,address,network{id,name},interface{id,name}} | 否 | 引用 IP 嵌套展开；interface 非空（归属要求） |
| protocol | enum | 否 | TCP\|UDP（大写） |
| port | int 1–65535 | 否 | 监听端口 |
| description | string\|null | 是 | 未设置 null |
| version | int≥1 | 否 | 乐观锁 |
| created_at/updated_at | ISO-8601 UTC | 否 | |
| deleted_at | ISO-8601 UTC | 是 | 未删 null |

列表响应 {items,page,page_size,total}。响应不含 metadata/原始 service_id/ip_address_id。

## 4. 分页/排序/过滤
- 分页：page 整数 ≥1 默认 1；page_size 1–100 默认 20；越界/非整数→422。
- 排序：sort∈{protocol,port,created_at,updated_at} 默认 created_at；order∈{asc,desc} 默认 desc；非法→422；附 id 升序稳定；sort=port 按数值。
- 过滤（AND）：
  - service_id=UUID（非 UUID→422；不存在→空结果）
  - ip_address_id=UUID（非 UUID→422；不存在→空结果）
  - protocol∈{TCP,UDP}（非法→422）
  - deleted∈{exclude,include,only} 默认 exclude
- 未列出参数忽略；条件仅作用于可见集合。不新增 cluster/resource 过滤参数（DR-167；§18/§19 聚合归 F013 或后续契约扩展）。

## 5. 软删可见性
列表 deleted∈{exclude,include,only} 默认 exclude；非法 422；include/only 需 VIEW_DELETED 否则 403 FORBIDDEN{reason:"permission"}。详情默认不可见软删对象；?deleted=true 需 VIEW_DELETED 否则 403；默认视图下软删返回 404（不泄露存在性）。Activity 对已删同理。

## 6. Endpoints

### 6.1 GET /api/v1/service-endpoints — READ（deleted=include|only 另需 VIEW_DELETED）
Query service_id/ip_address_id/protocol/deleted/page/page_size/sort/order（§4）。成功 200 列表。错误 401/403/422/500。

### 6.2 POST /api/v1/service-endpoints — WRITE
Request：service(必填 UUID)、ip_address(必填 UUID)、protocol(必填 §2.2)、port(必填 §2.2)、description(可选 null)；未列/只读字段（含 metadata）→422。成功 201 {"service_endpoint":ServiceEndpoint}；同事务写 CREATE Audit。
错误：401/403 / 409 CONFLICT{unique_conflict} / 422（body、service 缺失/不存在/软删 field="service"、ip_address 缺失/不存在/软删/未绑定/跨 Resource field="ip_address"、protocol 非法/null、port 越界/null）/ 500。
**校验顺序**：401→403→body(422，含只读/未知字段)→service(422，含存在/未软删)→ip_address 存在/未软删(422)→归属：interface 非空且 interface.resource_id==service.resource_id(422 field="ip_address")→protocol(422)→port(422)→监听唯一(409 unique_conflict)→写+Audit→201。
并发：监听唯一由部分唯一索引 `uq_service_endpoints_ip_protocol_port` 原子兜底。
**DB backstop（DR-158/DB-D150）**：归属结构性校验另由 `trg_service_endpoints_attribution` 兜底；应用为主校验。若 backstop 触发（`restrict_violation`）仍映射为 422 field="ip_address"，不暴露为 500。

### 6.3 GET /api/v1/service-endpoints/{id} — READ
id=UUID（非 UUID→404）；Query deleted(bool 默认 false；true 需 VIEW_DELETED 否则 403)。成功 200 {"service_endpoint":ServiceEndpoint}。错误 401/403/404/500。

### 6.4 PATCH /api/v1/service-endpoints/{id} — WRITE
Body（exclude_unset，省略=保持；含 version 必填 int≥1）：protocol(可选；∈{TCP,UDP})、port(可选；1–65535)、description(可选；显式 null 清空)；含 service/service_id/ip_address/ip_address_id/id/metadata/只读字段→422。
成功 200 {"service_endpoint":ServiceEndpoint}；version+1；写 UPDATE Audit（before/after）。
错误：401/403/404 / 409 VERSION_CONFLICT / 409 CONFLICT{unique_conflict} / 422。
**校验顺序**：401→403→body(422)→可见性(404)→version(409)→（若改 protocol/port）取值校验(422)→监听唯一重检(409，排除自身)→写+Audit→200。

### 6.5 DELETE /api/v1/service-endpoints/{id} — DELETE_OBJECT
Query version(必填 int≥1)。软删（置 deleted_at、version+1、updated_at）；不级联；无子对象引用 Endpoint，故删除前无需引用检查。成功 204；写 DELETE Audit。
错误 401/403/404/409 VERSION_CONFLICT/422/500。
**顺序**：401→403→对象(404)→version 校验(422)→版本(409)→软删。

### 6.6 POST /api/v1/service-endpoints/{id}/restore — RESTORE
Query version(必填 int≥1)。置 deleted_at=null、version+1、updated_at；仅恢复自身不级联；重检（§21/DR-166）：所属 Service 未软删/存在、ip_address 未软删/存在、归属成立（IP 已绑定 Interface 且 interface.resource_id==service.resource_id）、监听唯一；失败不覆盖新对象。成功 200；写 RESTORE Audit。
错误 401/403 / 404 / 409 CONFLICT{not_deleted} / 409 VERSION_CONFLICT / 409 CONFLICT{unique_conflict} / 409 CONFLICT{dependency_deleted,conflicts:[{object_type:"service"|"ip_address"|"interface",object_id}]} / 422 VALIDATION_ERROR{field:"ip_address"}（IP 已解绑或归属不再成立）/ 500。
**优先级（确定性）**：401→403→查找(含软删,404)→未删则 409 not_deleted→版本(409)→监听唯一(409 unique_conflict)→Service 依赖(409 dependency_deleted)→ip_address 依赖(409 dependency_deleted)→绑定 Interface 依赖(409 dependency_deleted)→归属成立(422 field="ip_address")→恢复。
说明：监听唯一优先于依赖失效；IP 未绑定 Interface 或 `interface.resource_id != service.resource_id` 属关系约束失败→422；依赖对象仍软删/缺失→409 dependency_deleted；不自动恢复 Service/IP/Interface。

### 6.7 GET /api/v1/service-endpoints/{id}/activity — VIEW_ACTIVITY（全角色）
Query deleted(bool 默认 false；已删需 true+VIEW_DELETED)、page/page_size。返回 (object_type="service_endpoint",object_id=id) 审计 created_at 升序、同刻 id 升序。成功 200 {items:[ActivityItem],page,page_size,total}；ActivityItem{id,action(CREATE|UPDATE|DELETE|RESTORE),operator_user_id(UUID|null),operator_username(string),before_data(object|null),after_data(object|null),created_at}。只读无修改/删除入口（§22）。错误 401/403/404/422/500。

## 7. 并发与错误语义小结
- 乐观锁：条件 UPDATE WHERE id AND version=:expected SET version=version+1；rowcount=0→对象仍可见则 409 VERSION_CONFLICT{current_version}，不可见/不存在则 404；无静默重试。
- 监听唯一：创建/改 protocol·port/恢复冲突 409 CONFLICT{unique_conflict}；DB `uq_service_endpoints_ip_protocol_port`（部分唯一 WHERE deleted_at IS NULL）并发兜底；软删释放。
- 归属：service/ip 存活与 Interface 同 Resource 为应用主校验；DB `trg_service_endpoints_attribution`（BEFORE INSERT/UPDATE，不检查软删、不加锁）兜底结构性归属。IP 绑定关系可 PATCH（F010），Endpoint 创建/恢复在该时点校验；backstop 触发映射 422 field="ip_address"。
- 引用：IP 解绑/转移/释放前由 F010 调用 IP 引用检查器，F012 provider 返回未删 Endpoint→409 reference_exists；Service 删除前由 F011 调用 Service 引用检查器，F012 provider 同理。
- 422=格式/字段/形状/归属非法；409=语义冲突；404=不可见/不存在；403=权限。

## 8. Audit 一致性（§22/D02）
四类 action 各写一行 audit_logs；同事务；object_type="service_endpoint"、object_id=ServiceEndpoint UUID；快照白名单 {service_id,ip_address_id,protocol,port,description}；UPDATE 记 before/after；不记敏感内容。Activity 按 (object_type,object_id) 过滤；完整跨对象审计归 F015/F016。

## 9. 业务边界
F012 交付 ServiceEndpoint 独立对象与 /api/v1/service-endpoints 7 端点，及两个引用 checking provider（IP 侧注册到 F010 `register_ip_address_reference_checker`、Service 侧注册到 F011 `register_service_reference_checker`）。不实现 Service 本体（F011）、IPAddress 本体与分配/解绑/转移/释放（F010）、§18/§19/§17/Dashboard 聚合（F013）、导入（F014）、完整 Audit（F015/016）。不支持通配地址 0.0.0.0/空监听地址、Unix Socket、跨资源共享 VIP、端口范围/列表、IPv6、URL/路径/TLS、健康检查/存活探测、端口实开探测、自动发现监听。不落 metadata/name/status/listen_address。未定义路径/方法 404/405；id 非 UUID 404。

**跨 Feature 契约**：
- F012 注册两个真实 provider 后，IP 解绑/转移/释放（§13.3/§16/T22）与 Service 删除（§16/§21/T23）的 `reference_exists` 端到端成立。
- 引用列表 `object_type` canonical=`"service_endpoint"`；F010 Contract/桩测试按 errata-03 订正（I-4/DR-162）。
- §18/§19/§17/Dashboard 展示归 F013（本 Feature 仅提供 Endpoint 数据）。
