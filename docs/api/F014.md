## 1. 通用约定

- Base path `/api/v1`，挂同一 `api_v1_router`（§25）。
- 认证：`csm_session` HttpOnly Cookie（复用 F002）；未认证先于权限返回 401。
- 操作者：服务端从 `request.state.operator` 取；写 Audit 的 operator 快照（§22）；请求体不接受操作者字段。
- CSRF：写入端点沿用 F002 §2.1（Origin/Sec-Fetch-Site）；预校验为安全读语义但按 POST 处理，同源校验沿用实现。
- 时间：ISO-8601 UTC；本 Feature 响应通常不含时间戳（审计行可经 Activity 查看）。
- 错误信封：`{"error":{"code":str,"message":str,"details":{}}}`（复用 F002 §1.1）。

### 1.1 权限

| 端点 | Capability | VIEWER | EDITOR | ADMIN |
| --- | --- | --- | --- | --- |
| `POST /imports/resources/validate` | `IMPORT` | 403 | 允许 | 允许 |
| `POST /imports/resources` | `IMPORT` | 403 | 允许 | 允许 |
| `GET /imports/resources/templates` | `READ` | 允许 | 允许 | 允许 |

未认证 401；已认证缺权限 403 `FORBIDDEN{reason:"permission"}`；CSRF 失败 403 `FORBIDDEN{reason:"csrf"}`。

### 1.2 错误码（本 Feature 新增，须登记 F002 §1.2 注册表）

| HTTP | code | 触发 | details |
| --- | --- | --- | --- |
| 413 | `IMPORT_FILE_TOO_LARGE` | 文件字节数 > 上限（解析前） | `{"limit_bytes": int}` |
| 413 | `IMPORT_ROW_LIMIT_EXCEEDED` | 数据行数 > 上限（校验前） | `{"limit_rows": int}` |
| 422 | `IMPORT_INVALID_FILE` | 不可解码/损坏/非 xlsx/空数据行/表头或列不符 | `{"reason": str, "missing_columns": [str]?, "unknown_columns": [str]?}` |
| 422 | `IMPORT_VALIDATION_FAILED` | 写入端点存在行错误（整批回滚） | `{"total_rows": int, "importable_rows": int, "error_count": int, "errors": [RowError], "errors_truncated": bool}` |

`reason` 取值：`unreadable`、`unsupported_format`、`header_missing`、`missing_columns`、`unknown_columns`、`column_order`、`empty_file`。

`RowError`：`{"row": int(1-based 文件行号), "field": str(模板列名), "reason": str, "related_row": int|null}`。

复用既有码：401 `AUTH_REQUIRED`、403 `FORBIDDEN`、422 `VALIDATION_ERROR`（`format` 缺失/非法）、500 `INTERNAL_ERROR`。

## 2. 请求

三个端点共用的 multipart 请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | binary | 是 | CSV 或 `.xlsx` 文件 |
| `format` | string | 是 | `csv` 或 `xlsx`（大小写不敏感） |

- 文件不落盘、不持久化；写入端点接收同一文件并完整重校验。
- 编码：CSV 为 UTF-8（兼容 BOM）；`.xlsx` 仅接受 OOXML，不接受 `.xls`。
- 上限：`import_max_file_bytes`（默认 5,242,880）、`import_max_rows`（默认 5000）。

## 3. `POST /api/v1/imports/resources/validate` — 预校验

- 权限 `IMPORT`；**无副作用、幂等、不写 Audit**（I-3）。
- 成功 200：

```json
{
  "format": "csv",
  "total_rows": 12,
  "importable_rows": 10,
  "error_count": 3,
  "errors": [
    {"row": 4, "field": "cluster",  "reason": "cluster does not exist or is not selectable", "related_row": null},
    {"row": 7, "field": "hostname", "reason": "duplicate hostname within file (also at row 2)", "related_row": 2}
  ],
  "errors_truncated": false
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `format` | string | 规范化后的请求格式 |
| `total_rows` | int | 数据行数（不含表头） |
| `importable_rows` | int | `total_rows - 出现错误的数据行数` |
| `error_count` | int | `errors` 计数（未截断时为全量） |
| `errors` | RowError[] | 聚合行错误；`errors_truncated` 为 true 时最多 `import_error_preview_limit` 条 |
| `errors_truncated` | bool | 是否因预览上限截断 |

- 错误：401/403；413（超限）；422 `IMPORT_INVALID_FILE`/`VALIDATION_ERROR`；500。

## 4. `POST /api/v1/imports/resources` — 写入

- 权限 `IMPORT`；同一事务再次校验；整批成功或整批回滚，回滚不留 Resource/明细/Audit/Activity（I-1/I-8）。
- 成功 201：`{"created": 10, "total_rows": 10}`；每行同事务写一条 CREATE Audit。
- 行错误 422 `IMPORT_VALIDATION_FAILED`（details 见 §1.2），整批未写入。
- 错误：401/403；413；422 `IMPORT_INVALID_FILE`/`IMPORT_VALIDATION_FAILED`/`VALIDATION_ERROR`；500。
- 写入顺序：解析+表头校验 → 上限 → 逐行只读校验（批内重复/现存冲突）→ 无错误则插入阶段（SAVEPOINT + Host `FOR UPDATE` + flush + Audit staging）→ 全部成功 `commit`，否则 `rollback`。

## 5. `GET /api/v1/imports/resources/templates` — 模板规范（A25）

- 权限 `READ`；只读、无 Audit。
- 成功 200：

```json
{
  "templates": [
    {
      "resource_type": "BARE_METAL",
      "columns": [
        {"name": "cluster", "required": true, "target": "resource.cluster",
         "type": "string", "unit": null, "enum": null,
         "description": "Cluster code (case-insensitive) or UUID; must exist and be undeleted",
         "example": "N96P"},
        {"name": "memory_mb", "required": false, "target": "hardware.memory_mb",
         "type": "integer", "unit": "MiB", "enum": null,
         "description": "Physical memory; empty = unknown (null)", "example": "262144"}
      ]
    },
    {
      "resource_type": "VIRTUAL_MACHINE",
      "columns": [
        {"name": "host", "required": true, "target": "virtual_machine.host_resource_id",
         "type": "string", "unit": null, "enum": null,
         "description": "Hostname (or UUID) of an existing, undeleted BARE_METAL host in the same cluster",
         "example": "cn001"}
      ]
    }
  ]
}
```

- 列集合/顺序以 `docs/features/F014/architecture.md` §5 为准；本端点只读暴露该冻结集合。
- 错误：401；500。

## 6. 模板列与校验（引用 architecture §5，不在本文件重复全表）

- BM 模板 14 列、VM 模板 10 列；表头第 1 行、数据自第 2 行；列名/顺序/必填/单位/枚举冻结。
- 空单元格（可选列）= 省略（默认/null）；必填列空 = 行错误；枚举取大写规范值（DR-199）。
- 单位：`memory_mb`=MiB、`disk_gb`=GiB（§8/§9，D01 §3）；`gpu_count`/`disk_gb`=0 表示「明确无」，未知为 null（I-12）。
- VM Host 引用列 `host` 解析为 `host_resource_id`；须满足 §9 四条件且同 Cluster，且**批外已存在**（I-9）。
