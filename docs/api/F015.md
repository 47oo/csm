## 1. 通用约定
- Base path `/api/v1`，挂同一 `api_v1_router`；认证 `csm_session`（F002）；未认证先于权限 401。
- 时间：ISO-8601 UTC。错误信封复用 F002 §1.1；错误码复用 F002 §1.2/§1.2.1（**不新增**）。
- `GET` 免 CSRF；`POST`/`PATCH` 沿用 F002 §2.1。写操作 operator 取自 `request.state.operator`。
- 分页基线：`page`≥1 默认 1；`page_size` 1–100 默认 20；越界/非法 422 `VALIDATION_ERROR{fields}`。

| 端点 | Capability | VIEWER | EDITOR | ADMIN |

## 2. `GET /api/v1/audit` — `AUDIT_READ`
只读完整审计查询（§22）；无请求体。

### 2.1 查询参数
| 参数 | 类型 | 必填 | 默认 | 规则 |
| --- | --- | --- | --- | --- |
| `operator` | string | 否 | — | `operator_username` 精确匹配（trim+小写归一）；trim 空或 >64 → 422 |
| `object_type` | enum | 否 | — | ∈{cluster,resource,interface,network,ip_pool,ip_address,service,service_endpoint,user}；非法 422 |
| `object_id` | UUID | 否 | — | **须与 `object_type` 同现**；单独提供 422；非 UUID 422 |
| `action` | enum | 否 | — | ∈{CREATE,UPDATE,DELETE,RESTORE}；非法 422 |
| `created_from` | ISO-8601 UTC | 否 | — | 闭区间下界；非法 422 |
| `created_to` | ISO-8601 UTC | 否 | — | 闭区间上界；`from>to` 422 |
| `page` | int | 否 | 1 | ≥1；越界/非整数 422 |
| `page_size` | int | 否 | 20 | 1–100；越界/非整数 422 |
| `sort` | enum | 否 | `created_at` | 仅 `created_at`；其它 422 |
| `order` | enum | 否 | `desc` | asc\|desc；非法 422 |

- 条件 AND；排序 `created_at`（order），同刻 `id` 恒升序；空结果 200 `{items:[],page,page_size,total:0}`；校验顺序 401→403→422→200。

### 2.2 响应（200）
```json
{"items":[{"id":"…","action":"UPDATE","object_type":"resource","object_id":"…","operator_user_id":"…","operator_username":"user01","before_data":{"status":"IDLE"},"after_data":{"status":"DOWN"},"created_at":"2026-10-06T12:00:00+00:00"}],"page":1,"page_size":20,"total":137}
```
**AuditRow**：id(UUID)、action、object_type、object_id(UUID)、operator_user_id(UUID\|null)、operator_username、before_data(object\|null)、after_data(object\|null)、created_at。**不含密码/令牌**。

### 2.3 错误
401 `AUTH_REQUIRED`；403 `FORBIDDEN{permission}`；422 `VALIDATION_ERROR`；500。无修改/删除/清空端点（A8/A30/T36）。

## 3. `GET /api/v1/deleted` — `VIEW_DELETED`
只读跨 8 类已软删聚合。

### 3.1 参数
| 参数 | 类型 | 必填 | 默认 | 规则 |
| --- | --- | --- | --- | --- |
| `object_type` | enum | 否 | — | 8 类（不含 user）；非法 422 |
| `page` | int | 否 | 1 | ≥1；越界 422 |
| `page_size` | int | 否 | 20 | 1–100；越界 422 |
| `sort` | enum | 否 | `deleted_at` | 仅 deleted_at；其它 422 |
| `order` | enum | 否 | `desc` | asc\|desc；非法 422 |

- 仅 `deleted_at IS NOT NULL`；同刻 object_type 升序、object_id 升序。

### 3.2 响应（200）
```json
{"items":[{"object_type":"network","object_id":"…","version":3,"label":"mgmt","cluster":{"id":"…","code":"N96P","name":"…"},"deleted_at":"2026-10-05T08:30:00+00:00"}],"page":1,"page_size":20,"total":6}
```
**DeletedItem**：object_type、object_id(UUID)、version(int≥1，供既有 restore `?version=`)、label(cluster=code；resource=hostname；interface/network/ip_pool/service=name；ip_address=address；service_endpoint="{protocol}:{port}")、cluster(object\|null)、deleted_at。不返回删除操作者。

### 3.3 恢复（复用，不新增写端点）
对 item.object_id + item.version 调用 §5 路由对应端点；语义以各域契约为准（I-15/A19）。

### 3.4 错误
401/403/422/500。无 404。

## 4. `/api/v1/users` — `USER_ADMIN`（§23）
无自行注册、无物理删除、无改密/重置；密码/令牌绝不进入响应或 Audit。

### 4.1 `GET /api/v1/users` — 列表
参数：`role`(VIEWER|EDITOR|ADMIN)、`status`(ACTIVE|DISABLED)、`q`(username 大小写不敏感子串；空/超长 422)、分页、`sort∈{username,role,status,created_at,updated_at}` 默认 created_at、`order` 默认 desc。响应 `{items:[UserRow],page,page_size,total}`。
**UserRow**：id、username、role、status、version、created_at、updated_at。**永不包含 password_hash**。

### 4.2 `GET /api/v1/users/{id}` — 详情
id 非 UUID → 404；成功 200 `{user:UserRow}`；不存在 404 `NOT_FOUND`。

### 4.3 `POST /api/v1/users` — 创建
| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `username` | 是 | trim+小写归一；`^[a-z0-9._-]{3,64}$` 否则 422 |
| `password` | 是 | 非空；长度 PROPOSED 8–128；argon2 hash，不回显 |
| `role` | 是 | VIEWER\|EDITOR\|ADMIN |

成功 201 `{user:UserRow}`；写 `object_type="user"`/`action="CREATE"` Audit（after={username,role,status}，同事务）。重复 username → 409 `CONFLICT{reason:"unique_conflict",field:"username"}`。错误 401/403/409/422/500。

### 4.4 `PATCH /api/v1/users/{id}` — 更新角色/状态
| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `version` | 是 | 乐观锁 |
| `role` | 否 | VIEWER\|EDITOR\|ADMIN |
| `status` | 否 | ACTIVE\|DISABLED |

role/status 至少一个（都缺 422）；未知/只读字段 422；username/password_hash 不可出现。成功 200 `{user:UserRow}`(version+1)；写 `object_type="user"`/`action="UPDATE"` Audit（before/after={username,role,status}，同事务）。角色变更即时生效；DISABLED 同事务删该用户全部 user_sessions，旧 Cookie 401 `AUTH_REQUIRED`、登录 401 `AUTH_INVALID_CREDENTIALS`；ACTIVE 恢复登录。错误 401/403/404/409 `VERSION_CONFLICT{current_version}`/422/500；顺序 401→403→body(422)→对象(404)→版本(409)。

### 4.5 不提供（404/405）
无 register/signup/匿名建号；无 `DELETE /api/v1/users/{id}`；无改密/重置/首登强制改密端点。

## 6. 错误码与业务边界
- 复用 F002 §1.2：401 `AUTH_REQUIRED`；403 `FORBIDDEN{permission|csrf}`；404 `NOT_FOUND`；409 `VERSION_CONFLICT{current_version}`；409 `CONFLICT{reason}`；422 `VALIDATION_ERROR{fields}`；500。F015 不新增 error code/reason。
- 未定义路径/方法 404/405。
- Audit 查询与已删列表只读无副作用。
- object_type 登记（待 Database 复核）：8 类 + `user`。

- `layers.database=false`；**无新表/新列/新约束/新触发器/新索引/迁移**；迁移链单 head 保持 `0013_search_indexes`。
