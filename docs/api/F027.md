# F027 服务端访问范围强制执行 — API 范围附录

- 状态：READY
- 版本：v1（2026-10-21）
- 签核：Architect
- 依据：requirements revision 11 §23.2；F027 product/architecture；F026 `docs/api/F026.md` v1；F013/F018、F014/F023、F019/F022 既有 Contract
- 范围：为既有端点增加范围语义，不新增端点/字段/权限项/error code

## 1. 通用

- 认证载体、CSRF、错误信封、时间、分页/排序/过滤沿用各域既有 Contract。
- 有效权限 = 角色矩阵 ∩ 对象所属 Cluster 在授权集合内；ADMIN 不受限；非 ADMIN 零授权默认拒绝。
- 范围逐请求解析，不缓存；授权/角色变更下一请求生效。
- 错误顺序：401 → 403 → 422 → 404 → 409。

## 2. 读

- 列表：`items`、`total`、分页、过滤均只覆盖可见 Cluster；未授权 Cluster 的过滤值返回空 200；不出现空页 total>0。
- 详情：未授权对象 404 `NOT_FOUND`，响应不含对象字段。
- Activity：未授权对象 404；完整 Audit 仍仅 ADMIN。
- 已删对象：非 ADMIN 的 `include`/`only`/`deleted=true` 仍 403；ADMIN 行为不变。
- 搜索：4 类候选、F018 关联行、`related_total`、`total` 仅覆盖可见 Cluster；匹配/去重/排序/分页/字段组合不变。
- Dashboard：`counts`、`networks`、容量仅覆盖可见 Cluster；零授权全 0/空 200；公式不变。

## 3. 写

- 创建/修改/删除/释放/恢复/分配/绑定/解绑/转移：未授权对象 404；请求体显式引用未授权/不可选 Cluster 或父对象 422 `VALIDATION_ERROR`。
- 跨 Cluster 变更同时校验当前对象与目标 Cluster；当前对象不可见 404，目标未授权 422；既有同 Cluster 完整性不变。
- 被拒绝写操作不产生业务变更、关联变化、Audit、Activity；事务边界不变。
- 导入：预校验与写入按行范围校验，错误含行号/字段/原因；存在范围外行整批失败、无残留；模板/列集/上限/两步流程不变；`--push` 同口径。
- 接口侧逐条绑定：未授权条目 404，其他条目独立。

## 4. 不泄露

- 任何响应/计数/搜索/错误/导入行错误不得包含未授权 Cluster 的 code/name/id/状态/规模。
- 范围校验先于唯一性/重叠/引用检查；不得通过 409 或字段回显泄露未授权对象存在。
- Q1（EDITOR 创建 Cluster）维持既有 §23/F003 行为；Cluster code 唯一性 409 仅返回 `field:"code"`，不回显其他 Cluster 信息，记录为窄例外。

## 5. 既有 Contract errata

- F013 Dashboard `counts`：由“全局未删”改为“可见范围未删”；`networks` 同口径；公式不变。
- F002：范围不可见对象沿用 404；不新增 error code/reason。
- 各域 Contract：增加“未授权对象 404、body Cluster 422、列表/total 范围收敛”的交叉引用；字段/端点/错误码不变。
- F014/F023：导入行范围错误沿用既有行错误结构与整批原子回滚；模板/列集/上限不变。
- F017/F026：API Key 继承与授权管理不变。
