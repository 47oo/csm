# CSM 前端 UI 技术栈

状态：CONFIRMED
适用范围：V3 一期前端呈现层
记录日期：2026-10-12

## 1. 选型

CSM 前端使用 Ant Design 6.6.x 提供有状态交互与数据展示组件，使用 Tailwind CSS 4.3.x 负责应用自有布局、间距和响应式。React、TypeScript 与 Vite 保持需求 §29 已确认的技术栈，不增加路由或状态管理库。

依赖通过 `frontend/package.json` 与 `frontend/package-lock.json` 固定兼容版本。Vite 使用官方 `@tailwindcss/vite` 插件；Ant Design 在应用根节点配置简体中文 locale、浅色主题和紧凑算法。

## 2. 职责边界

Ant Design 负责按钮、输入、选择、复选框、数据表、反馈、卡片、标签、分页及确认对话框等有状态界面元素。`frontend/src/components/ui/` 保存全站共享展示原语，其中兼容适配层保留原有 DOM 事件形状，使迁移不改变既有表单状态、请求参数、权限门控与错误处理。

Tailwind CSS 负责应用壳、页面布局、间距、对齐、窄屏换行和滚动容器。应用样式只选择 CSM 自有类名或 Ant Design 对外公开的组件属性；不得依赖 Ant Design 内部 DOM 层级或生成类名进行深层覆盖。

## 3. 行为兼容

本次选型只改变呈现层。认证恢复与 401 跳转、403 权限提示、409 版本冲突、422 字段错误、服务端分页与排序、软删除、恢复、两阶段整批导入等行为继续由现有 React 状态和 API 模块控制。兼容组件不得静默重试、自动覆盖版本冲突、把未知值转换为 0，或把请求失败显示为空数据。

表格横向内容使用 Ant Design 的滚动能力；过滤区和操作区允许在窄屏换行。所有交互组件保留键盘焦点、可见禁用态、关联 label 及现有 ARIA 属性。中文文案和业务术语保持不变。

## 4. 升级策略

Ant Design 仅在 6.6.x 兼容范围内升级，Tailwind CSS 仅在 4.3.x 兼容范围内升级。跨次版本升级需重新运行 TypeScript 检查、生产构建、客户端 smoke 回归和全页浏览器巡检；若组件事件或渲染契约变化，应优先在 `components/ui/` 适配，不把库差异扩散到业务页面。

## 5. 布局与操作层级

2026-10-21 呈现层维护，依据用户「让前端布局和样式更现代化，按钮布局更合理」的明确要求与需求 §28；延续上述技术栈、业务行为和权限契约，不修改 Feature 历史交付状态。

桌面（≥1024px）使用左侧分组导航、顶部用户区和独立内容区。选中入口同时用背景、边线和 `aria-current` 表达；提供跳转主要内容链接，切换页面后聚焦内容区。宽表格在自身区域横向滚动，页面容器可收缩。Dashboard 的五类计数在宽屏均分为五列，较窄屏幕切换为三列或两列。

全站使用浅色表面、蓝色主操作、统一圆角与间距。Ant Design 主题仍由 `main.tsx` 管理，应用壳与布局样式由 `index.css` 管理，字体使用本地系统字体。保留紧凑算法并适当增大控件高度；尊重 `prefers-reduced-motion`。

共享 `Button` 的 `variant` 只控制视觉层级，`type` 保持 HTML 提交语义；未显式指定 variant 的现有表单继续按原有规则呈现。列表新建和详情编辑为主要操作，导入、返回和重置为次要操作。资源页两类导入收进同一点击菜单，各自展开/收起状态与原有权限保持一致。详情页编辑与删除分开排列，确认弹窗继续复用现有组件。表格「操作」列由共享表格组件统一加间距，筛选区与页面操作区分区显示。

### 5.1 2026-10-23 呈现层维护（F033）

依据 `docs/features/F033/architecture.md` v1（DR-F033-01..11）与用户 2026-10-23「更新前端布局与不合理 CSS」要求。本节只改呈现基线，不改 §1/§2/§4 的技术栈与职责边界，也不改 §3 的行为兼容约定。

**断点与壳层**

| 断点 | 壳层与容器 |
| --- | --- |
| ≥1024 | 224px 左侧栏；顶部用户区 `position: sticky`（`z-index:30`，低于弹层与跳转链接）；导航竖排 42px；内容 `--csm-content-gutter:32px` |
| ≤1023 | 单列壳层：侧栏变为内容上方的一条紧凑区（`padding:10/16`，brand 32px，英文副标题收起）；导航改为**单行横向滚动**（`nowrap` + `scroll-snap` + 右缘渐隐提示 + 44px 触达），分组标签与侧栏注脚隐藏；header 回到静态流（不 sticky）；gutter 20px |
| ≤767 | Dashboard 计数卡两列，末张奇数卡跨满整行；筛选/表单整行；详情单列；gutter 16px |
| ≤480 | gutter 12px；装饰性 eyebrow 隐藏；导航字号 12px；角色标签与 header 内边距收紧（375 壳层首屏占用 ≤180px） |
| ≥1280 | Dashboard 计数卡五列 |

**容器宽度**：不再用 `main` 元素选择器统一裁宽。`.boot-main`（≤720px）、`.login-main`（460px）、`.workspace-content`（`width:100%` + `--csm-content-max:1600px` + 居中 + `min-width:0`）各自声明；页面级只用内容自身滚动，禁止 `html`/`body` 的 `overflow-x:hidden` 掩蔽横向溢出。

**页头层级**：当前页只由内容区唯一 `h1`、`main[aria-label]` 与导航 `aria-current="page"` 表达，header 只保留用户身份与登出入口；装饰性 eyebrow 带 `aria-hidden` 并在 ≤480 隐藏。桌面 sticky header 由 `html{scroll-padding-top}` 与 `.workspace-content{scroll-margin-top}` 保证跳转与焦点不被遮挡。

**语义 token 单一来源**：`frontend/src/index.css` 的 `:root` 是全站唯一颜色字面量来源（`--csm-*`：主色、文本、表面、边框、语义态、阴影、焦点环、圆角、间距、字阶、容器与断点尺寸），应用自有类只引用 token，取值与 `main.tsx` 的 Ant token 对齐；不新增 Ant Design 内部选择器覆盖，颜色字面量不出现在 `:root` 之外。

**渐进披露**：搜索卡「Resource 行展示字段」9 项选择器改为原生 `<details>/<summary>`，默认折叠（不写 `open`、不持久化展开态），内部保留 `role="group"`；偏好键值、默认选中集、请求参数与结果集不变。摘要行保持 44px 触达、原生键盘可操作，并使用统一焦点环。

**局部布局**：授权面板用 `grid` 双栏（≥1024，`minmax(240px,1fr) minmax(0,2fr)`）与单列（≤1023，账号列表按钮 44px），移除组件内 inline 样式；宽表格继续使用共享表格的横向滚动，容器与卡片补齐 `min-width:0`。

### 5.2 2026-10-26 呈现层维护

依据用户「将前端样式不合理的地方进行修改，使其更自然」的要求与需求 §28，维护现有呈现基线；不涉及产品规则、API、数据库或技术栈变更。

* 保留紧凑算法，Ant Design 字号种子调整为 16，使常规控件正文为 14px；编号、IP、时间等 `.mono` 使用固定 13px 和等宽数字，避免相对字号叠加缩小。占位文字使用次要文字色，标题使用 600 字重。
* 小号卡片使用 `headerHeightSM=48` 与 `headerFontSizeSM=17`，与正文中的面板标题一致。共享 `SurfaceCard` 通过 Ant Design 公开 `classNames` / `styles` 属性和 `--csm-card-padding` 处理布局；内边距为 24px，在 ≤767px 时为 16px。
* 表单控件与按钮采用 6px 圆角，筛选区为 8px，卡片保留 10px；统计卡使用浅中性色表面，去掉装饰性顶边。搜索字段折叠区与下方提示保留 16px 间隔；分区标题只有实际位于容器首项时才取消顶部间距。
* 软删可见性是辅助筛选：宽屏限宽 320px，≤767px 占满可用宽度。常规筛选项使用 200px 弹性基准，保留换行与已有提交行为。
* 资源新建 / 编辑表单在 ≥768px 使用按 DOM 顺序排列的双列，≤767px 单列；描述、JSON、分区标题、反馈和操作栏跨满整行。标签自然换行，字段错误保留在相应控件下方。

验证与截图见 [2026-10-26 UI 维护记录](../project/ui-polish-2026-10-26.md)。
