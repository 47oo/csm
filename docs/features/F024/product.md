## 1. 目标与范围

提供一个可在目标 Linux 主机**本地手工运行**的采集脚本，读取本机已知信息并生成符合 §24.1 已冻结模板的导入文件，减少人工逐列填写。

范围内（CONFIRMED）：
- **定位**：脚本是导入模板的**生产者**，不是导入通道。**离线、只读、手动**：不连接 CSM、不调用平台 API、不上传、不写库；不创建或修改任何 CSM 对象。
- **输出**：默认 CSV（UTF-8，兼容 BOM），表头列名与列序与 §24.1 / D03 冻结的第三套模板逐字一致；`.xlsx` 不作为一期必需。
- **自动采集**：hostname、CPU（型号/插槽/整机物理核心数）、内存容量、GPU 型号/数量、网卡名称/类型/MAC/速率/MTU、本机 IPv4 地址等，按 D01 归一化与单位口径输出。
- **人工补全**：无法可靠获得的业务/归属字段 `cluster`、`resource_type`、`role`、`status`、`host`、`network` 一律留空，由人工补全；不写占位或推断值。
- **权限**：无 root 时优先读免特权来源（如 `/sys/class/dmi/id`），其余特权字段留空且不报错、不自动提权。
- **模板冻结**：不修改、不扩展 F014 / F023 模板、契约或既有导入行为。

## 2. 明确不做

- 不做平台自动采集 / Agent / 常驻 / 调度 / Facts 回传，不改变 §3 / §34 排除项。
- 不连接、不写入、不上传 CSM；不绕过 §24 两步流程与同一 Service Layer 校验。
- 不创建或导入 Network / IP Pool / Cluster / Host。
- 不从主机推断 `resource_type`、`role`、`status` 等业务值。
- `.xlsx` 一期非必需；不随 Compose 分发。
