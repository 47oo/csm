# F033 前端布局与 CSS 质量优化 — PRODUCT 阶段报告

- **状态**：READY FOR ARCHITECT
- **版本**：v1
- **上游依据**：`docs/product/requirements-v3.md` revision 12 §28（运维控制台；快速、清晰、高效查询与低操作成本；不追求复杂视觉效果）；`docs/architecture/frontend-ui-stack.md` §2/§3/§5（现有布局与组件基线）；用户 2026-10-23 明确要求「更新下前端布局，以及不合理的布局和CSS样式」；plan revision 19（F033，depends_on F028 DONE）。
- **说明**：仅呈现层质量优化，不新增业务规则、API、Schema、权限或交互语义。

## 1. 目标与范围

在不改变业务行为、数据、权限和既有交互语义的前提下，让控制台在 1440 / 1024 / 768 / 375 视口下更快到达内容、减少无效滚动与横向拖动、视觉更一致。

| # | 当前问题 | 本次范围 |
| --- | --- | --- |
| S1 | 移动端壳层过高：sidebar 242px + header 65px，3×3 导航占 148px，首屏内容起点约 307px | 收敛移动端导航与顶部区，显著降低首屏占用；导航入口不丢失 |
| S2 | header 的「工作空间 / 当前页」与 page heading 标题重复 | 同一信息只保留一处，不新增信息位 |
| S3 | 搜索「Resource 行展示字段」9 项常驻展开，移动端搜索卡约 945px | 默认折叠，可键盘展开；已保存偏好、默认选中集、请求参数不变 |
| S4 | System 授权面板 inline 固定双栏在窄屏不堆叠 | 窄屏单列堆叠；宽屏保持双栏 |
| S5 | CSS 散落硬编码颜色；`main` 全局 720px 与 workspace 1600px 冲突 | 收敛语义 token、容器宽度与间距；保留 Ant Design + Tailwind 边界 |
| S6 | Dashboard 移动端 5 张计数卡最后一张独占半列 | 窄屏等宽排布，无孤立半列 |
| S7 | 桌面 header 不粘性，长表格滚动后用户/登出入口不可见（可选） | 由 Architect 评估实现或明确维持现状 |

不包含：页面改版、新信息架构、动效体系、图标重绘、主题切换、路由/状态库/组件库升级。

## 2. 明确不做

- 不新增或修改业务规则、字段可见性、权限口径、API、Schema 或服务端分页/排序/过滤语义。
- 不改变登录/401/403/409/422 呈现、删除/释放/恢复二次确认、导入两阶段流程。
- 不新增路由、状态管理库、UI 组件库或第二套基础组件；不升级 Ant Design/Tailwind 次版本。
- 不重构业务页面数据流；只改受影响布局、共享样式与必要呈现层。
- 不删除现有 CSS class 与 `components/ui/` 兼容路径；不搞全站重写。
- 不新增深色模式、国际化、主题配置或用户自定义布局偏好。

## 3. 领域与数据影响

无新增实体、关系、状态、唯一性、字段或生命周期；无数据完整性影响。搜索字段偏好仅改变默认展开状态，不改变存储键、已保存值与提交参数。

## 4. 验收标准

在 1440×900、1024×768、768×1024、375×667 巡检 Dashboard、Search、Resources/Resource Detail、Clusters/Cluster Detail、Networks、Services、Audit、System（含授权面板）、登录页。

| # | 可观察行为 |
| --- | --- |
| A1 | 无页面级横向溢出（`documentElement.scrollWidth ≤ clientWidth`）；宽表格只在自身容器滚动 |
| A2 | 375px 下导航+顶部区合计高度 ≤ 200px；首屏可见页面标题与后续内容；导航入口可达且有当前态 |
| A3 | 768/1024/1440 导航可达；切页后内容区获得焦点；跳转主要内容链接可用 |
| A4 | 页面标题不再与 header 重复表达同一信息 |
| A5 | 768/375 下 System 授权面板单列堆叠，无重叠/裁切；1024/1440 保持双栏 |
| A6 | Search 字段组默认折叠，展开后 9 项可用；偏好、默认选中集、请求参数与结果不变 |
| A7 | Dashboard 375px 计数卡无孤立半列；各断点列数符合既有基线 |
| A8 | 语义 token 单一来源；宽表页面大屏不被 720px 容器收窄；浅色表面+蓝色主操作+统一圆角间距 |
| A9 | 既有列表/详情/表单/弹窗/权限/错误行为与 F028 基线一致；`smoke:client` 全量通过 |
| A10 | 若实现桌面粘性 header：滚动后用户/登出入口可见且不遮挡内容；否则报告明确维持现状 |
| A11 | `npm run typecheck`、`npm run build` 通过；无新增控制台错误；同步 `frontend-ui-stack.md` §5 与共享组件说明 |
