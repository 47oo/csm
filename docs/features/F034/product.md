## 1. 目标与范围

F034 让维护人员**无需先把 CSV 存成文件**，即可在既有导入入口粘贴 CSV 文本完成与文件导入完全等价的「预校验 → 确认 → 写入」。

范围内（CONFIRMED）：

1. **两个入口并列新增文本载体**：`ResourceImportPanel`（F014 资源导入，BM 14 / VM 10 列模板）与 `ResourceInterfaceIpImportPanel`（F023 资源+网卡+IP，26 列模板）都在「选择文件」之外提供「粘贴 CSV 文本」。文件上传（含 `.xlsx`）保留、行为不变、不被替换。
2. **载体只改变输入方式，不改变导入语义**：文本按 UTF-8 编码为 CSV 字节后走既有预校验 / 写入端点，模板列集与列序、两步流程、Service Layer 校验、`RowError`（`row` / `field` / `reason` / `related_row`）、行号口径（表头第 1 行）、`IMPORT` 权限、§23.2 集群范围行级拒绝、Audit 口径、整批原子回滚、字节 / 行数上限全部与文件载体一致（§24.5「口径一致」「等价性」）。
3. **文本仅 CSV**：不提供 `.xlsx` 的文本载体；文本载体固定 `format=csv`。
4. **表头严格同口径**：文本必须自带与冻结模板逐字逐序一致的表头；缺表头 / 缺列 / 未定义列 / 列序不符按既有 `IMPORT_INVALID_FILE` 原因拒绝；不静默忽略、不按列名重排、不自动补表头、不做分隔符嗅探、不做列名大小写折叠。
5. **上限按 UTF-8 字节与行数**：字节上限按文本 UTF-8 编码后的字节数适用同一已签核上限值；行数上限与文件载体一致；数值不变更、不新增配置项。
6. **不持久化**：粘贴内容不落盘、不入库，不写入 Audit / 日志 / 错误响应。
7. **陈旧结果防护**：修改文本内容或在文件 / 文本载体之间切换后，既有预校验与写入结果必须失效、不可确认导入，须重新预校验（可观察要求在 T116）。

## 2. 明确不做

- 不新增平台 API：不新增端点、查询参数、请求字段、错误码 / `reason`、上限或权限；不改 `format` 取值语义。
- 不修改 F014 / F023 的模板、列集、列序、端点、校验口径、上限与既有导入行为；不改写其历史交付证据。
- 不修改数据库 Schema / Migration / 索引 / 约束；不改后端导入实现、权限矩阵与 Audit 规则；不改技术栈、不新增前端依赖。
- 不支持用文本更新或覆盖现存对象（§24 仅新增）；不导入或创建 Network / IP Pool / Cluster / Host / Service / Endpoint。
- 不支持分隔符嗅探（含从 Excel 复制的制表符文本）、不自动补表头、不做列名映射或大小写折叠、不做前端 CSV 解析或前端业务校验的第二权威。
- 不做 `.xlsx` 文本粘贴、多文件批量、流式上传、跳过预校验直接写入。

## 4. 边界与风险（产品视角）

- 文本与文件必须给出**同一结论**：任何「文件失败、文本成功」（或反向）的差异都视为缺陷，含表头、分隔符、BOM、行尾与行号口径。
- 用户从 Excel 直接复制得到制表符分隔内容时，按 CHG012-BQ02 = A 会失败；界面须明确提示「仅逗号分隔、必须包含与模板一致的表头」，不作为放宽依据（若需嗅探应另立需求）。
- 粘贴内容属用户数据，不得因实现便利落入浏览器存储、URL、控制台或错误消息。
