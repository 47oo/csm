## 关键路径

`F001 → F002 → F005 → F006 → F011` 为最长实施链（含依赖收敛），是决定 P0 完成时间的关键路径。`F008`（搜索）被 `F004` 与 `F011` 依赖；`F007`（服务）被 `F010` 依赖。
