# CSM V2 Milestones（派生视图）

> 本文件由 `docs/project/project-plan.yaml` 派生，只引用计划事实。若与计划冲突，以计划为准。
> 计划状态：**DRAFT — 等待用户批准**。全部 Feature 为 P0。Milestone 按产品可交付能力组织，不表示批准或已开始。

## M1 — 集群与计算资源基础台账

- **目标**：打通集群登记、计算资源一次录入、统一列表与详情，可替代核心 Excel 台账。
- **Feature**：F001、F002、F003
- **退出标准**：requirements-v2.md §10 场景 1–9、32–34 通过；一次提交原子性与名称唯一生效。
- **前置**：架构前提 D-ARCH-*、D-Q3、D-STATUS-SOURCE 已裁定。

## M2 — 网段与 IPv4 分配台账

- **目标**：集群多网段维护、保留地址与 IPv4 手动/自动分配闭环。
- **Feature**：F005、F006
- **退出标准**：§10 场景 10–12、19–31 通过；并发与耗尽场景在基线环境验证。
- **前置**：D-Q5、D-IP-SEMANTICS。

## M3 — 类型详情、宿主关系与服务部署

- **目标**：打通裸金属/VM 专有详情、宿主双向关系与服务部署实例关联。
- **Feature**：F004、F007
- **退出标准**：§10 场景 13–18、35–36 通过；VM 宿主约束与服务集群约束生效。
- **前置**：D-Q3、D-IP-SEMANTICS、D-BQ-E。

## M4 — 统一检索、权限审计与集群聚合

- **目标**：落实全量模糊搜索规范、三角色服务端鉴权审计与集群聚合概览。
- **Feature**：F008、F009、F010
- **退出标准**：§10 场景 37–41 通过；§8、§9.1 生效。
- **前置**：D-BQ-F。

## M5 — 非功能与可用性基线

- **目标**：在约 1000 台/集群基线上验证分页、可靠性、原子性与可用性要求。
- **Feature**：F011
- **退出标准**：§9.2–§9.4 与场景 7、9、22、23、39 通过。
- **前置**：D-BQ-F（正式延迟目标、备份/恢复演练）。
