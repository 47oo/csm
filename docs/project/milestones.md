# CSM V2 Milestones（派生视图）

> 本文件由 `docs/project/project-plan.yaml` 派生，只引用计划事实。若与计划冲突，以计划为准。
> 计划状态：**ACCEPTED — 用户已批准 revision 6（2026-09-24）**；产品需求整体仍为 DRAFT，实施门禁独立适用。全部 Feature 为 P0。
> Milestone 按产品可交付能力组织，顺序保证任一 Milestone 的 Feature 只依赖本 Milestone 或更早 Milestone 的 Feature；
> 退出标准按 `closure_owner` 只引用在本 Milestone 或更早已闭环的 §10 场景（其余为 parts），不在依赖未完成时承诺验收。

## M1 — 集群、计算资源登记与网络台账

- **目标**：打通集群登记与身份保护、网段与保留地址、IPv4 分配，以及计算资源一次原子录入（公共信息 + 无 IP 网卡 + 全部 IP）与统一列表/详情，可替代核心 Excel 台账。
- **Feature**：F001、F005、F002、F006、F003
- **Milestone 内实施/验收顺序**：F001 → F005 → F002 → F006 → F003
- **退出标准（闭环）**：§10 场景 **3、4、8–12、19–21、24–32、34、43–48、50、52、53** 由 M1 内 Feature 闭环通过；
- **M1 内验收的部分（parts）**：场景 **2**（同名裸金属/名称唯一）、**5**（网卡/IP 归属）、**6**（唯一性与网卡/IP 可见）、**42**（网络内容/公共信息不变）、**51**（计算资源与有效网段关联）；各场景的 VM 同名（F004）、服务与 VM 关联（F004/F007）分别在 M2/M3 闭环。
- **其他验收**：一次提交（含 IP）原子性、资源/接口/名称唯一、IPv4 并发唯一、跨重叠排除、耗尽与释放规则验证通过；M1 退出时同一表单支持一次录入公共信息 + 全部网卡 + 全部 IP。
- **交付分段说明**：F002 先交付表单与整单原子基础（含类型字段容器、无 IP 网卡与网段选择）；F006 在同一表单集成 IP 分配、管理 IP 与含 IP 的整单原子。**F002 DONE 时只验收公共信息、类型字段容器（不含 VM 必填宿主）与无 IP 网卡，不承诺 IP 与 VM 注册**。详情“服务”列与服务关联保护由 M3 的 F007 承接，类型摘要与类型详情由 M2 的 F004 承接。“无 IP 网卡”“服务列后置”“类型详情后置”均为交付分段，不是产品限制。
- **前置**：D-ARCH-*、D-STATUS-SOURCE、D-NAME-COMPARISON、D-IP-SEMANTICS、D-SEGMENT-RETENTION。

## M2 — 统一检索、类型详情与宿主关系

- **目标**：落地统一模糊搜索与下拉规范的基础能力与已交付对象适配，并基于其与既有列表/详情完成类型专有详情、类型摘要与宿主双向关系。
- **Feature**：F008、F004
- **Milestone 内实施/验收顺序**：F008 → F004（F008 依赖 M1 的 F002/F003；F004 同时依赖 M1 的 F003）。
- **退出标准**：§10 场景 **1、2、13–15、33、35、36、41** 通过；场景 **37/38 的已交付对象基础部分**通过（最终 closure 留待 M4 的 F011）；场景 **18（VM 关联部分）**、场景 **42（类型详情不变部分）**通过；VM 宿主约束、类型摘要与已交付对象的基础搜索匹配规则生效。
- **前置**：D-ARCH-*、D-Q3。

## M3 — 服务、权限审计与集群导航

- **目标**：打通服务与部署实例、三角色服务端鉴权审计、集群聚合概览与独立全局 IP 查询，并闭环集群删除保护与服务/VM 关联可见性。
- **Feature**：F007、F009、F010
- **Milestone 内实施/验收顺序**：F007 与 F009 依赖 M1；F010 依赖同 Milestone 的 F007 与 M1/M2。
- **退出标准**：§10 场景 **5、6、16–18、40、42、49、51、54–57** 通过；§4.8 服务删除保护、§6.1 统计口径、§6.2 全局 IP 查询、§9.1 权限生效；场景 **42 的既有网卡/IP/公共信息不变**由 M1 的 F006 验收，本 Milestone 闭环类型详情（F004）与 VM/服务关联（F007）不变；场景 **51 三类关联（计算资源/有效网段/服务关联）齐全的最终闭环**通过。
- **前置**：D-ARCH-*、D-BQ-E、D-SERVICE-DETAILS、D-NAME-COMPARISON、D-BQ-F。

## M4 — 非功能与可用性基线

- **目标**：在约 1000 台/集群基线上端到端复核分页、可靠性、原子性、并发与竞态防护要求，并闭环全部搜索面全量覆盖。
- **Feature**：F011
- **退出标准**：§9.2–§9.4 与 §10 场景 **7、22、23、37、38、39** 通过；场景 **37/38 在所有搜索面（含 F004 宿主、F007 服务与服务实例、F010 全局 IP 查询）交付后完成全量覆盖闭环**。
- **前置**：D-ARCH-*、D-BQ-F（正式延迟目标、备份/恢复演练）。
