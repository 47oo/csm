## 问题与结果

| 实际问题 | 修改结果 |
| --- | --- |
| 紧凑主题下控件文字偏小，编号 / 时间再次按 em 缩小 | 调整主题字号和占位文字对比度，等宽文字固定 13px |
| 使用 Card 标题的面板比正文 h2 标题明显小 | 统一小号卡片标题高度、字号与标题字重 |
| 软删可见性下拉框横跨整行 | 桌面限宽 320px，窄屏自然占满 |
| 资源表单全宽单列、页面过长 | 宽屏双列，长文本和反馈跨列，窄屏单列；新建和编辑共用 |
| 首个分区标题被 first-of-type 错误去掉顶部间距 | 仅 first-child 取消间距，恢复统计卡与网络容量标题的分隔 |
| 字段折叠区与提示贴合、窄屏卡片内边距偏大 | 增加区块间距，卡片通过公开语义属性响应式切换 24 / 16px 内边距 |
| 统计卡装饰性蓝色顶边与数据争夺注意力 | 使用浅中性色表面，保留计数与标签 |

长期布局规则唯一维护于 `docs/architecture/frontend-ui-stack.md` §5.2。代码修改集中于 `frontend/src/index.css`、`frontend/src/main.tsx`、`frontend/src/components/ui/surfaces.tsx`、`frontend/src/components/ResourceForm.tsx`。无新增依赖。

技能适配：UX 检索 `text reflow spacing` 命中 Web「Text Reflow and Spacing」，用于自然换行、可收缩容器与窄屏检查。初始 React 响应式检索无匹配，重试 `component composition` 后只采用组件组合这一通用建议；数据集标注 React 19.2，不将其作为项目 React 18 的版本升级依据。Ant Design 属性以本地安装版本类型定义核验。
